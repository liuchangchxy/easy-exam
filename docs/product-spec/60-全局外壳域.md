## 1. 域定位与边界

**定位**：全局外壳是横切所有屏幕的一层，负责「用户在任何页面都能预期到的同一套框架行为」——导航与跳转、返回与来路、面包屑与页名、命令面板、主题/语言/密度、账户菜单与登录态、对话框与确认的唯一实现、成功反馈的唯一实现、菜单/抽屉/快捷键、加载/失败/空/禁用/无权限八态、跨端断点与软键盘/安全区、全局操作、同步态与多标签页。它为总册「操作与交互逻辑」提供事实基础。

**边界（属于其他域，本册只定义外壳侧契约）**：
- 题库工作区/题目页/复习队列/模考/资料/导入/设置的**域内交互**归各自分册；本册只规定它们必须服从的外壳契约（返回、URL 状态、对话框/确认/toast、快捷键、八态、断点）。
- 学习会话的**判分/FSRS/斩杀/错题**业务归学习域；本册只定义 runner 的**外壳**（全屏结构、退出确认、开始决策面板、快捷键统一、软键盘）。
- 视觉（配色取值/字号/间距/圆角/阴影）归 P2 视觉分册；本册只写**结构与行为**，不写样式取值。

**设计方向**：Direction D · Editorial Precision 已冻结（深色书脊侧栏 + 居中纸面 + 1px 编辑式分隔线）。本册不触碰视觉语言。

## 2. 功能定义

### FN-601 应用外壳与导航
- **存在目的与场景**：为每个已登录页面提供同一套框架（侧栏 + 顶栏 + 移动顶栏 + 底部导航 + 品牌），让用户在任何屏幕都找得到「我在哪、怎么去别处、怎么返回、怎么改偏好、怎么退出」。
- **入口与适用条件**：`AppLayout`（`frontend/src/layouts/AppLayout.vue`）包裹所有一级/二级页（home/banks/bank-detail/question/review/exams/notes/settings/instance/import/forbidden）。全屏 runner（practice/exam）用 `FullscreenLayout`（`frontend/src/layouts/FullscreenLayout.vue`），不带侧栏/底栏。登录页与强制改密页是 `App.vue` 的组件门禁，不走 AppLayout。
- **可执行操作**：点击侧栏/底栏导航项跳转；点击品牌回今天；顶栏搜索/主题/语言/账户；移动端返回/更多菜单；命令面板。
- **操作结果**（含数据与状态变化）：导航触发 `router.push`，`afterEach` 记录应用内历史栈（`backNavigation.js`）；`document.body.dataset.route` 更新为当前路由名（`AppLayout.vue:421-423`），供测试/样式按路由分区；进入 home/review/banks 时刷新外壳计数（due/banks/trends，`AppLayout.vue:428-431`）；离开时关闭所有外壳菜单。
- **与其他功能的关系**：承载 FN-602~FN-617；命令面板（FN-605）与账户菜单（FN-608）由外壳持有；对话框/确认/toast（FN-609/610）在 `App.vue` 挂载一次、全局可用。
- **当前缺失与不合理之处**（标注证据）：
  - 原型已把侧栏/底栏/品牌全部变成**真链接**（`assets/nav.js` 的 `ROUTES` 唯一契约 + `.side-brand → home.html`）；生产侧品牌仍是 `<button @click="navigate('today')">`（`AppSidebar.vue:3-9`），导航项也是 `<button>`（`AppSidebar.vue:13-26`、`MobileNav.vue:3-17`），**无法新标签打开或复制链接**——这是生产现状（§5.6「0 个 router-link」经 P1 已在面包屑与题库行名引入 3 处 `router-link`，但侧栏/底栏/品牌仍未链接化）。
  - 原型底部第 6 格「更多」按既定决策直接进 `settings.html`（`nav.js` ROUTES `'更多'/'More': 'settings.html'`），不再做只开不动的浮层；生产侧「更多」开一个 `chrome-more-menu`（设置/主题/语言，`AppLayout.vue:150-171`）。两者模型不同（见 Q-605）。
- **理想完成态**：侧栏/底栏/品牌均渲染为 `router-link`/`a`（可中键打开、可复制、可分享深链）；当前项 `aria-current="page"` + `.is-active`；面包屑父级可点击回到真实上层；命令面板、账户菜单、主题/语言全屏可用；外壳不持有任何业务数据，只通过事件（`easyexam:banks-changed`）刷新计数。

### FN-602 一级导航 5+1 职责定义
- **存在目的与场景**：5 个学习主区 + 1 个设置，构成产品模块树（SPEC §2.0）的界面骨架。
- **入口与适用条件**：侧栏 `.side-nav` 五项 + `.side-foot` 设置；底部导航 6 格（今天/题库/复习/模考/资料/更多）。`AppSidebar.vue:75-81`、`MobileNav.vue:34-41`。
- **可执行操作**：切换到任一区。
- **操作结果**：路由跳转 + 当前项高亮 + 计数徽章（题库数/资料数/复习到期数，`AppSidebar.vue:24-25`；原型 `nav.js` COUNTS 从共享状态读）。
- **与其他功能的关系**：`currentPage` 由路由名反推（`AppLayout.vue:264-274`），驱动高亮、面包屑、页名、命令面板。
- **当前缺失与不合理之处**（标注证据）：
  - `import`（导入）被硬编码算进「题库」区（`AppLayout.vue:267` `n === 'import' → 'banks'`），侧栏/底栏无独立导入项；从模考进导入，页内唯一出口是「题库」（§5.6 记录，P1–P6 未改）。原型同理，导入只能从题库/工作区上下文进入（`nav.js` 导入向导带 `?bank=`）。
  - 移动端底栏在 `/settings` 与 `/instance` 时**无任何项高亮**（底栏无设置项，`currentPage='settings'` 不匹配任何 `bn-item`，`MobileNav.vue:34-41`）——§5.6 记录，未修（见 GAP-611）。
  - `instance-admin` 导航高亮归「设置」组（`AppLayout.vue:272`），但它是 `requiresAdmin` 独立路由（见 FN-608/PR-603）。
- **理想完成态**：
  - **今天**：继续上次 · 今日队列（到期/错题/薄弱/斩杀恢复，带原因）· 概览。
  - **题库**：列表（我的/共享给我）→ 工作区 → 题目页；承载「导入」这一下游动作的归属。
  - **复习**：复习队列（全部/到期/错题/薄弱/斩杀，`all` 默认）+ 学习档案（趋势/掌握度/完成率）。
  - **模考**：档案与蓝图 → 考试 → 报告（含历史报告）。
  - **资料**：笔记与文件（可关联题目）。
  - **设置**：个人偏好 · AI 与检索 · 账户 · 实例管理（仅管理员）。
  - 导入、实例管理在导航中的归属明确（见 Q-604）；设置/实例页在移动底栏有可识别当前位置。

### FN-603 返回与来路
- **存在目的与场景**：二级页（工作区、题目页、403）提供「返回」；语义是**回到来路**，不是走到一个假定的父页面。
- **入口与适用条件**：顶栏 `.page-back` 与移动顶 `.page-back-mobile`（`AppLayout.vue:13-24`、`60-71`）；仅当 `hasBack` 为真时渲染（`AppLayout.vue:346` = 有历史 或 有 fallback）。
- **可执行操作**：点击返回。
- **操作结果**（含数据与状态变化）：**有应用内历史 → `router.back()`**；**无历史（深链/书签/刷新落地）→ 走 `meta.fallback`**（`AppLayout.vue:355-369`）。`bank-detail`/`question` 的 fallback 分别是 `{name:'banks'}` / `'bank-detail'`（`router/index.js:25,29`）。回退到题库列表时**回放上次题库列表 query**（`readStoredBankListQuery()`，`AppLayout.vue:364-366`）。历史栈由 `recordNavigation` 维护，浏览器后退会 pop 而非 push，深度不漂移（`backNavigation.js:18-26`）；`canGoBack = 栈深 > 1`（`backNavigation.js:34`）。
- **与其他功能的关系**：与 FN-604 面包屑协同（面包屑表达层级，返回表达来路，两者不混）；`meta.back` 静态父级已在 P1 全部删除（`router/index.js` 只剩 `meta.fallback`）。
- **当前缺失与不合理之处**（标注证据）：
  - 全屏 runner（practice/exam）**没有接入应用内历史栈返回**，退出走各自的 in-app 退出确认（见 FN-616）；浏览器后退/刷新在 runner 内**不经过退出确认**（无 `onBeforeRouteLeave`/`beforeunload`，全仓仅 `ImportView.vue:2067` 有路由离开守卫）——见 GAP-604。
  - 原型返回控件同样遵循「有历史回退、无历史 fallback」，但原型是静态 HTML，`window.history` 跨页后退由浏览器承担，未维护应用内栈（原型 `nav.js` 只管滚动恢复）。
- **理想完成态**：返回=历史优先、fallback 兜底、fallback 回放列表现场；全仓无静态父级假设；runner 的浏览器后退/刷新也进退出确认（见 GAP-604）。

### FN-604 面包屑与页面标题
- **存在目的与场景**：顶栏面包屑表达**真实层级**，`document.title` 表达**当前页名**，让用户与浏览器标签都知道「我在哪」。
- **入口与适用条件**：顶栏 `.crumb`（`AppLayout.vue:25-33`）。
- **可执行操作**：点击面包屑中的上层链接。
- **操作结果**：`题库 › 题库名 › 第 N 题`；中间层是 `router-link` 回工作区（`AppLayout.vue:29`）；父级 `题库` 是 `router-link :to="{name:'banks'}"`（`AppLayout.vue:26`）。`document.title = 页名 · 易考宝`（`AppLayout.vue:371-374`），页名优先题目名 > 题库名 > 实例管理名 > 分区名（`AppLayout.vue:307-312`）。
- **与其他功能的关系**：与 FN-603 互补；题目页是层级叶子，自我命名（`questionTitle`，`AppLayout.vue:296-300`）。
- **当前缺失与不合理之处**（标注证据）：
  - 原型实测面包屑：question=`题库 / 验收题库 / 第 1 题`（3 级，正确）；workspace=`题库 / 验收题库`；import=`题库 / 导入题目`；instance=`设置 / 实例管理`；但 **review/exams/notes=`学习 / X`、settings=`今天 / 设置`**——把导航分组标签「学习」或「今天」当作面包屑父级，`设置` 的父级写成「今天」在语义上不成立（探针 round1）。生产侧只对 `bank-detail`/`question` 渲染面包屑父级（`AppLayout.vue:314-317`），其余页顶栏只有返回 + 泛化分区名（`sectionLabel`，`AppLayout.vue:276-286`）。
  - 原型面包屑父级是 `button.link`（CONTRACT §2），点击不导航（静态页限制）。
- **理想完成态**：面包屑只表达真实可达层级；叶子页自我命名；`设置` 不挂「今天」父级；每个列表/工作区页有 `PageHeader`（层级 + 标题 + 动作），不用与页签重复的位置说明。

### FN-605 命令面板
- **存在目的与场景**：一个「搜索与跳转」入口，既能跳页面，也能对题库直接「打开/练习」，减少多点按。
- **入口与适用条件**：顶栏搜索按钮 + 顶栏搜索框聚焦 + `Ctrl/⌘+K`（`CommandPalette.vue:277-282`；原型 `spec-boot.js` 三处同入口，`data-ee-shell="search"` / `search-input` / `Ctrl+K`）。
- **可执行操作**：输入过滤；`↑/↓` 选择；`Enter` 打开选中项；`Esc` 关闭；点击行；题库行有次级「练习」按钮。
- **操作结果**（含数据与状态变化）：打开即清空 query、焦点进输入框、锁背景滚动并补偿滚动条宽度（`CommandPalette.vue:189-230`）；默认展示前 5 个题库 + 全部命令（`CommandPalette.vue:149-160`）；`↑/↓` 循环（`moveSelection`）；`Enter` 对题库行=打开、命令行=执行（`executeSelected`）；关闭回焦到打开时的触发元素（`CommandPalette.vue:232-241`）。完整 combobox 语义：`role=combobox` + `aria-expanded/controls/activedescendant` + listbox/option（P5/§13.4 补齐）。
- **与其他功能的关系**：命令来自 `AppLayout.commands`（`AppLayout.vue:592-604`）；题库行打开走 `handleSelectBank`、练习走 `handlePracticeBank→handleStart`（复用统一开始决策，见 `FN-203` 与 `OP-609`）。
- **当前缺失与不合理之处**（标注证据）：
  - 生产 `commands` 11 条中 **6 条（今天/题库/复习/模考/资料/设置）等同侧栏**（`AppLayout.vue:592-604`），加上 drafts/ai/theme/locale/logout；**缺导入、新建题库、错题、斩杀、按条件开始练习**等非导航命令（§5.6 记录，P1–P6 未改命令清单，只补了 a11y）。原型命令面板是「页面跳转」清单（`spec-boot.js` 从 `nav.js` ROUTES 生成），同样是导航副本。见 GAP-605 / Q-601。
  - 原型 question 页顶栏**无可见搜索入口**（只有 `Ctrl+K`），banks 顶栏「搜索与跳转」未标 `data-ee-shell`（探针 round3），搜索入口未全屏一致。
- **理想完成态**：命令面板 ≠ 侧栏副本；至少含：页面跳转、题库检索（打开/练习）、**新建题库/题目、导入、错题、斩杀、到期复习、开始练习、切换主题/语言、退出**；每个非显然命令带说明与快捷键徽章；空态有引导；全屏一致入口（图标 + `Ctrl/⌘+K`）。

### FN-606 主题（明暗 / 配色 / 密度）
- **存在目的与场景**：用户可持久选择外观；满足 SPEC §8「四套配色 × 浅色/深色/跟随系统，切换即时生效并持久化，启动零闪烁」。
- **入口与适用条件**：顶栏主题按钮（`AppLayout.vue:39-41`，`ThemeToggle.vue`）；设置页外观区（`SettingsView.vue:48-56` 明暗分段、`SettingsView.vue` 配色、`SettingsView.vue:96-108` 密度）；登录/强制改密页也有主题按钮（`App.vue:5`、登录屏实测有「深色」）。
- **可执行操作**：切换明暗；切换配色（editorial/gruvbox/everforest/catppuccin）；切换密度（balanced/dense）。
- **操作结果**（含数据与状态变化）：
  - 明暗：`useTheme.toggleTheme` 在 system 模式下切到当前解析色的反色（`useTheme.js:131-136`）；写 `easyexam-theme-mode`/`easyexam-theme`（`themePreference.js:158-167,197-206`）；`syncRoot` 应用 `data-theme` + `data-theme-palette` + `color-scheme`，并同步 `meta[name=theme-color]` 为当前 `--surface`（`useTheme.js:40-70`）。
  - 跟随系统：`mode='system'` 时监听 `prefers-color-scheme`（`useTheme.js:72-105`），`resolveEffectiveTheme` 解析（`themePreference.js:220-225`）。
  - 密度：`SettingsView` 写 `easyexam-density`（dense/balanced）+ `data-density`（`SettingsView.vue:520-524`、`density.js`），`main.js` 首渲染前 `restoreDensityPreference`（`main.js:20`）。
  - 零闪烁：`main.js` 在 `mount` 前 `initializeLocale/initializeTheme/restoreDensityPreference`（`main.js:18-20`）；`index.html` 有静态 `theme-color` 首绘兜底（`index.html` 注释）。
- **与其他功能的关系**：主题/语言/密度是全局部级状态（ST-601/602/603）；主题色同时驱动浏览器 chrome 着色。
- **当前缺失与不合理之处**（标注证据）：
  - **「跟随系统」在设置 UI 不可选**：`useTheme` 完整支持 `system`（`THEME_MODES=['light','dark','system']`，`themePreference.js:49`），但 `SettingsView` 明暗分段只有 **2 项**（`SettingsView.vue:51-56`），`mode==='system'` 时两段都不高亮。这与 SPEC §8「浅色/深色/跟随系统三种模式」冲突——见 GAP-601。
  - **自定义强调色已被下线**：`LEGACY_ACCENT_STORAGE_KEY` 成了死键，`clearLegacyAccentPreference` 启动即删（`themePreference.js:11,212-218`），注释明确「强调色归配色家族，不再是独立偏好」。SPEC §8 仍要求「用户可自定义强调色且 AA 4.5:1」——见 GAP-602 / Q-602。
- **理想完成态**：明暗三态（含跟随系统）均可选且当前态可识别；四套配色独立于明暗；密度 balanced/dense；全部持久化、零闪烁、即时生效；浏览器 `theme-color` 跟随。自定义强调色按 Q-602 裁定（恢复或修订 SPEC）。

### FN-607 语言（i18n）
- **存在目的与场景**：根级双语无刷新切换并持久化（SPEC §8）。
- **入口与适用条件**：顶栏语言按钮（`AppLayout.vue:42-44`，`LocaleToggle.vue`）；设置页语言分段（`SettingsView.vue:130`）；登录屏有「EN」（实测）。

  - **无全局同步/离线指示器**：外壳顶栏不显示「同步中/离线/最后同步时间」，只有 runner 内在断网时有横幅（`ExamView.vue:51`）。§13.3 明列「未做多标签页并发编辑同一草稿（后写覆盖先写）」。

  - 多标签页同时开同一会话/同一草稿无冲突提示（后写覆盖）。见 Q-604。
- **理想完成态**：顶栏/设置显示同步态与最后同步时间；离线有明确提示且已加载会话可继续；冲突给「保留两个版本/选择」而非静默覆盖（SPEC §6）；全局 401 → 清会话并回登录（记住原目标）；多标签登录/退出一致。

## 3. 业务规则（BR-6xx）

- **BR-601 返回 = 历史优先**：返回按钮先 `router.back()`（有应用内历史时）；无历史（深链/书签/刷新）才走 `meta.fallback`；fallback 是「回退基准」不是「父级」；回退到列表回放上次列表 query。禁止静态父级假设。（`backNavigation.js`、`AppLayout.vue:355-369`）
- **BR-602 状态进 URL**：筛选/排序/页码/页签/选中/题目/向导步骤进 URL；默认值不写地址、空值删除、变化才 replace；`pageSize` 等设备偏好可留 localStorage。（`routeQuery.js`）
- **BR-603 权限改变能力，不改变结构**：无编辑权时控件**禁用 + 可读原因**，不隐藏入口；不可进的地方给 403 页，不隐藏后再让后端报错。（§7.0.4、`store.js can()/denyReason()`）
- **BR-604 一个实体一个规范页面**：页面数量由实体数量决定，不由权限/历史决定；`/banks/:id` 是唯一工作区，`/banks/:id/manage` 仅作保留 query 的重定向（`router/index.js:28`）。
- **BR-605 未登录 → 登录并回跳**：未登录渲染登录页；登录成功后回到原目标（hash 天然保留目标，`App.vue` 组件门禁）。（§9.2）
- **BR-606 非成员 / 不存在 → 403/404 整页**：后端 403（非成员）或 404（库不存在）→ `AccessDeniedState` 整页说明 + 返回题库列表；其它失败仍可重试 banner。（`AccessDeniedState.vue`、`guards.js`）
- **BR-607 唯一确认 / 唯一成功反馈**：确认统一 `ConfirmHost/AppDialog`（缺宿主回落 `window.confirm`）；瞬态成功统一 toast；持久结论统一页内 notice。（`useConfirm.js`、`useToast.js`）
- **BR-608 外观偏好持久化 + 零闪烁**：明暗/配色/密度/语言存 localStorage，`main.js` 首渲染前恢复，`index.html` 首绘兜底；切换即时生效。（`main.js:18-20`、`index.html`）
- **BR-609 快捷键不劫持输入**：全局快捷键在输入框聚焦时不触发（除命令面板 `Ctrl/⌘+K` 这类明确全局键）；`Esc` 关最顶浮层。
- **BR-610 点击目标 ≥44px + 焦点可见**：`pointer:coarse` 下主交互 ≥44px（无法长高的加 44×44 `::after` 命中区）；焦点态 `:focus-visible`。（§14.1、`AppLayout.vue:795-799`）
- **BR-611 焦点管理**：浮层打开焦首项/关回焦触发器；对话框焦点陷阱 + Esc + 初始焦点 + 关闭回焦。（`AppDialog.vue`、`CommandPalette.vue`）
- **BR-612 实例角色 ≠ 题库角色**：账户菜单/设置显示实例角色（管理员/普通用户）；题库内只显示「你在本题库的角色」；不用同一个「管理员」指两者。（§12.1）

## 5. 权限规则（PR-6xx）

- **PR-601 未登录**：只见登录页（`App.vue` 门禁）；任何深链都先登录再回跳（BR-605）。后端未认证业务接口返回 401（实测 `GET /banks` 无 token → 401 `authentication required`）。
- **PR-602 已登录普通用户**：可见全部学习主区与个人设置；不能进实例管理（`meta.requiresAdmin` 被 `adminGuard` 拦到 `/forbidden?kind=forbidden&from=...`，`guards.js:22-24`）。
- **PR-603 实例管理员**：`users.is_admin` 为真可进 `/instance`（`InstanceAdminView`）；守卫在硬刷新直达管理 URL 时会刷新一次用户再判（`guards.js:15-22`）。注册开放（实测 `POST /auth/register` 201），首位用户/最早用户成为管理员（§12.1）。
- **PR-604 实例角色 vs 题库角色分离**：账户菜单/设置显示实例角色；题库内显示本题库角色（所有者/编辑者/成员）；不混用「管理员」一词。（§7.9、BR-612）
- **PR-605 无编辑权 → 禁用不隐藏**：共享库无编辑权仍可进工作区，编辑类控件禁用 + `denyReason` 说明，不隐藏入口。（`store.js can()/denyReason()`、§7.9）
- **PR-606 强制改密拦截**：`must_change_password=1` 时，除 `change-password`/`logout`/`me` 外所有业务 API 被后端 403；前端强制呈现改密表单，改密成功前禁入主系统。（SPEC §4.4、`App.vue:3-42`）
- **PR-607 数据权限归后端**：路由守卫只判「是否登录」与「能否进实例管理」；是否某库成员由后端 403 兜底，落到 `AccessDeniedState`。（`guards.js` 注释、§7.9）

## 9. 未决问题（Q-6xx）

- **Q-601 命令面板的范围**
  - 问题：命令面板应是「页面跳转清单」还是「动作面板」？
  - 分歧：现实现（生产 `AppLayout.commands`、原型 `nav.js` ROUTES）都是导航副本；合理完成态希望它能执行动作（新建/导入/开始练习/斩杀/错题）。
  - 候选方案：A 维持纯跳转；B 跳转 + 高频动作 + 题库检索；C 完全动作化（跳转交给侧栏）。
  - 推荐与理由：**B**。既保留「快速去哪」，又减少多点按，且不与侧栏职责重复。
  - 未裁定时的默认行为：维持 B 的最小集（页面跳转 + 题库打开/练习 + 主题/语言/退出），后续迭代加动作。
- **Q-602 自定义强调色**
  - 问题：SPEC §8 要求可自定义强调色（AA 4.5:1），但生产已将其下线（`themePreference.js` 注释：强调色归配色家族）。
  - 分歧：产品真理（SPEC §8）vs 已落地实现（四配色家族各自带强调色）。
  - 候选方案：A 恢复自定义强调色选择器；B 修订 SPEC §8 删除该条，声明「强调色=配色家族属性」；C 保留家族强调色 + 允许在家族内微调。
  - 推荐与理由：**B 或 C**。家庭/小团队规模下，四套精选配色的可读性比任意取色更稳；若要保留自定义，必须带 AA 校验。
  - 未裁定时的默认行为：以四套配色家族的强调色为准，不暴露任意取色。
- **Q-603 两个 runner 的快捷键统一**
  - 问题：练习 `F`=标弱、模考 `F`=标旗；练习 `Enter`=提交、模考无 `Enter`（§5.6/§7.3）。P3 提出统一但实施记录未确认落地。
  - 分歧：语义统一（同一键同一意）vs 保留各自语境（标记类型不同）。
  - 候选方案：A `F` 统一切到「标记」并二级选类型；B 拆键（练习 `W`=薄弱、模考 `B`=旗标）；C 维持现状。
  - 推荐与理由：**B**（或 A 的轻量版）。避免同键不同义造成的误操作；提交/交卷键两 runner 对齐。
  - 未裁定时的默认行为：先以代码复核两 runner 当前绑定，若仍不一致则按 B 统一，并在快捷键帮助中明示。
- **Q-604 多标签页 / 多设备并发冲突策略**
  - 问题：同一账号多标签或手机+电脑同时编辑同一会话/草稿，现为后写覆盖（§13.3 明列不做）。
  - 分歧：静默合并（省事）vs 显式冲突（安全）。
  - 候选方案：A 保持后写覆盖 + 轮询最终一致；B 版本号/乐观锁，冲突时提示「保留两个版本/选择」（SPEC §6）；C 仅对会话类做锁，草稿类保持覆盖。
  - 推荐与理由：**C**。会话（作答）冲突影响成绩，需显式；草稿是「我的续做点」，覆盖可接受。
  - 未裁定时的默认行为：会话类给冲突提示（runner 已有 `draft-conflicts` 横幅雏形，`ExamView.vue:55`），草稿类后写覆盖。
- **Q-605 账户菜单与移动「更多」的内容模型**
  - 问题：生产账户菜单仅「改密 + 退出」，移动「更多」= 设置/主题/语言；原型账户菜单= 账户资料/实例管理/退出，底部「更多」直接进设置。

  - 问题：文档 §12.1 记录 `GET/DELETE /auth/sessions`，实测 v1.0.24 普通用户 404。
  - 分歧：是路径不同、需管理员、还是未随该构建发布。
