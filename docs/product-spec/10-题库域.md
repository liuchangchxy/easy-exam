## 1. 域定位与边界

**解决的问题**：题目内容的「家」——题库的建立、组织（章节树 + 知识点标签）、题目的创建与版本化编辑、内容的批量维护、归档与恢复、导入与导出。题库域对学习主线（学习域）只承诺一件事：**提供稳定、可追溯、可寻址的题目内容与题目版本**；学习状态（作答、错题、FSRS、斩杀、掌握度）不归本域。

**包含实体**：题库（question_banks）、题库分类（category，非实体，题库上的一个字段）、章节（chapters，库内树）、知识点标签（knowledge_tags + question_tag_items）、题目（questions）、题目版本（question_versions）、题库—题目归属（bank_question_items，1:1）、导入作业（import_jobs）、导入草稿（import_drafts）、PDF 校对草稿（pdf_import_drafts）、题目冲突（question_conflicts）、题库审计（audit_logs，entity_type='BANK' / 'QUESTION'）。

**与其他域的分界**：
- **学习域**：练习/复习/模考会话、作答、判分、错题、FSRS、斩杀、掌握度。本域只向它暴露「可练题目池」与「题目版本快照」；斩杀不影响题库内容量、只影响我的可练题量，口径见 CR-04。
- **模考域**：进行中模考**不锁定**题库内容（CR-26，原 BR-117/118 的锁定口径作废）；被引用题被归档/移动/复制时的提示由本域执行。
- **协作与实例域**：题库角色（所有者/编辑者/成员）与实例角色（管理员/普通用户）的定义、成员增删改、转移所有权、越权页面。本域只消费角色结论（PR-1xx），不重复定义角色规则。
- **资料与设置域**：AI 变式题草稿的产生与 AI 配置、个人笔记/资料。本域只提供「AI 草稿」工作区页签这一容器与「采纳草稿→生成题目」的闭环。
- **全局外壳域**：导航、返回、URL 契约的通用机制；本域只规定本域页面写哪些 URL 键。

**明确不做**：不做整库复制（复制以题目为单位，BR-102）；不提供题库的通用物理删除——仅**空库**可物理删除且须输入库名确认，其余一律归档（CR-03、Q-101 裁定 B）；不把 AI 生成内容当标准答案（SPEC §2.3）；不做服务端题目分页（分页为客户端行为，见 FN-109）；不提供无题目上下文的独立内容管理外壳（P-5：题库是学习材料的家，不是数据库管理台）。

## 2. 功能定义

### FN-101 题库列表
- **存在目的与场景**：用户进入「题库」后的第一屏，回答「我有哪些题库、哪些是别人共享的、哪些已归档」。
- **入口与适用条件**：主导航「题库」→ `/banks`。未登录由外壳门禁拦截（全局外壳域）。
- **可执行操作**：搜索（名称/说明/分类）、分类筛选、排序（最近更新/名称/题库内容量）、视图切换（全部/已归档）、行勾选、行内菜单（编辑资料、导出 JSON、导出 CSV、归档题库）、行级「开始练习」「管理」（进入工作区设置页）、已归档行「恢复」。
- **操作结果**（含数据与状态变化）：筛选/排序/视图写入 URL 与浏览器会话级存储（具体存储方式是实现载体，P-12）（`?q=&category=&sort=&view=all|archived`），刷新/后退/分享可复现；列表分「我的题库 / 共享给我」两段，共享行带角色徽章；已归档视图只列已归档题库且只提供「恢复」（归档可恢复，CR-03）；每张卡片与每行显示「共 N 题 · 我可练 M 题」（CR-04）。
- **与其他功能的关系**：行「管理」→ FN-108 工作区（`?tab=settings`）；行「开始练习」→ 学习域统一开始入口（OP-110）；行菜单导出 → FN-107。
- **当前缺失与不合理之处**：行菜单导出只有 JSON/CSV 两种格式且不能选「包含已归档」，与工作区设置页的四格式 + 含归档导出不一致（`BanksView.vue:274-275` vs `BankManageView.vue:1121,650-655`）；已归档视图无批量恢复（后端 `POST /banks/batch` 已支持 `restore`，`banks.py:126-133`）——Q-106 裁定 B：保持单行恢复，不做批量恢复，属有意取舍而非缺陷。
- **理想完成态**：导出入口统一为一处（格式集 JSON/CSV/TXT/XLSX + 「包含已归档」开关）；已归档视图保留「只恢复、不批量」的低频设计，但行内给与批量条一致的可见禁用原因（R9：与当前用户相关但此刻不可用 → 禁用并解释）。

### FN-102 新建题库
- **存在目的与场景**：建立一个新题库，成为导入或手动建题的容器。
- **入口与适用条件**：题库列表页头「新建题库」、空态主操作；任何登录用户可建（建后自动成为所有者）。
- **可执行操作**：填名称（必填）、分类（留空=默认分类）、说明；保存或取消（有未保存修改时先问「丢弃这次编辑？」）。
- **操作结果**：创建 `question_banks` + `question_bank_members(role='ADMIN')`，写审计 `BANK_CREATED`；成功后跳转 `/banks/{新id}`（工作区题目页签）；外壳题库列表缓存通过 `easyexam:banks-changed` 广播刷新。
- **与其他功能的关系**：建库后通常接 FN-124 导入或 FN-111 手动建题。
- **当前缺失与不合理之处**：无。分类留空不落本地化文案的处理正确（`BanksView.vue:784-785`）。
- **理想完成态**：保持现状；新建成功后若题库为空，工作区空态应同时给出「导入」与「新建题目」两个出口（现状已具备，`BankManageView.vue:290-294`）。

### FN-103 编辑题库资料
- **存在目的与场景**：改名、改分类、改说明。
- **入口与适用条件**：题库列表行菜单「编辑资料」；仅所有者（`BanksView.vue:270-273` 禁用 + 原因）。
- **可执行操作**：改名称/分类/说明，保存或取消；未保存修改有关闭确认。
- **操作结果**：`PATCH /banks/{id}` 更新三字段，写审计 `BANK_UPDATED`；空分类=保持原值，不把界面语言写进共享数据。
- **与其他功能的关系**：改名影响面包屑、顶栏、分享链接可读性；不影响题目与学习数据。
- **当前缺失与不合理之处**：题库列表行菜单与工作区设置页都能改资料（两个入口同一动作），但不构成断裂；可接受。
- **理想完成态**：资料编辑收敛到工作区设置页一处，列表行菜单只保留导出与归档（P-4 同一动作一个位置）。

### FN-104 题库分类管理
- **存在目的与场景**：分类是题库上的一个字符串字段，用于列表筛选与分组。
- **入口与适用条件**：题库列表工具栏「分类管理」；至少拥有一个自己是所有者的题库时可点。
- **可执行操作**：选择分类 → 重命名或删除；删除后该分类下题库回到默认分类。
- **操作结果**：重命名批量改写用户名下所有题库（含已归档）的 category，逐库写审计；删除回填默认分类并写审计；默认分类不可删（`bank_repository.py:250-251`）。
- **与其他功能的关系**：仅影响 FN-101 的筛选/分组。
- **当前缺失与不合理之处**：分类只覆盖「我是所有者」的库（`bank_repository.py:217-224`），共享给我的库不参与重命名——语义正确但界面上没有说明，用户可能误以为全局生效。
- **理想完成态**：对话框内明示作用范围（「只影响你所有的题库」）；分类重命名后列表筛选值同步更新（现状已处理，`BanksView.vue:902`）。

### FN-105 题库批量操作（多选题库）
- **存在目的与场景**：一次归档多个题库或统一设置分类。
- **入口与适用条件**：题库列表勾选行后出现批量条；仅当所选全部为本人所有者身份时可执行。
- **可执行操作**：归档（需确认对话框）、设置分类（输入框 + 按钮）。
- **操作结果**：`POST /banks/batch` 单事务执行；任一条目不存在或越权，整批拒绝且无部分写入（`bank_repository.py:168-201`）；逐库写审计。题库归档**不**因库内有进行中模考被拒（CR-26）。
- **与其他功能的关系**：归档 → FN-106。
- **当前缺失与不合理之处**：批量条只暴露归档与设分类，后端已支持的 `restore` 未暴露（已归档视图只能单行恢复）。
- **理想完成态**：保持「归档 + 设分类」两个高频动作；批量恢复属于低频，不做（Q-106 裁定 B，与已归档视图只恢复的设计一致）。

### FN-106 题库归档与恢复、空库物理删除
- **存在目的与场景**：把整个题库移出主列表而不丢数据；反操作是恢复。**题库只有一种「移出视野」的动作：归档**（CR-03）。
- **入口与适用条件**：列表行菜单「归档」、工作区设置页「危险操作 → 归档题库」；仅所有者。**不因库内有进行中模考而禁用**（CR-26）。
- **可执行操作**：确认归档（危险确认框，标题带库名，**不要求输入库名**）；已归档行「恢复」；**空库物理删除**（仅所有者，无任何题目且无任何作答引用，**必须输入库名确认**）。
- **操作结果**：归档写 `question_banks.is_deleted=1`（软删除=归档，命名债见 GAP-121），工作区不可再进入；恢复后回到列表原排序位置。空库物理删除真正移除题库行并写审计。归档不影响题库内题目的归档位，不影响历史作答/模考外键。
- **与其他功能的关系**：归档不影响历史数据；被归档题库的进行中会话仍按快照完成。
- **当前缺失与不合理之处**：无空库物理删除入口（见 Q-101）；归档后从其他成员的「共享给我」列表消失，但对方的进行中会话仍可用（`get_version_for_session` 快照兜底），界面无提示。
- **理想完成态**：归档确认框写明「练习记录与历史数据保留，可随时恢复」；空库物理删除在库内无任何题目且无任何作答引用时才可用，输入库名确认；归档时若库内有其他成员的进行中会话，明确提示「N 位成员的进行中会话仍可完成，新考试将不再包含这个题库」（CR-26）。

### FN-107 题库导出
- **存在目的与场景**：把题库内容备份/迁移出来。
- **入口与适用条件**：列表行菜单（JSON/CSV）、工作区设置页导出面板（JSON/CSV/TXT/XLSX + 包含已归档开关）；任何成员可导出（导出是读操作）。
- **可执行操作**：选格式、（设置页）勾选包含已归档，点导出。
- **操作结果**：`GET /banks/{id}/export?format=&include_archived=` 返回文件下载；导出内容=内容管理同源数据（含创建/更新时间戳）。
- **与其他功能的关系**：导出格式与 FN-124 导入格式互为逆操作（JSON/Markdown/CSV/XLSX）。
- **当前缺失与不合理之处**：两处入口格式集不一致（FN-101 已记）；导出只导当前内容，不含题目版本历史与学习统计（Q-107 裁定 A：导出定位是内容备份，学习统计属个人学习档案，混入会扩大分享面）。
- **理想完成态**：统一为一处入口、四格式、含归档开关；导出文件内标注题库名与导出时间；导出内容边界固定为「当前在用题目，可选包含已归档」，**不含版本历史、不含任何学习统计**。

### FN-108 题库工作区
- **存在目的与场景**：一个题库的唯一规范页面，承载题目/结构/成员/导入历史/AI 草稿/设置六个页签。
- **入口与适用条件**：`/banks/:id`（`/banks/:id/manage` 为保留 query 的重定向，`router/index.js:28`）；非成员得到整页 403/404 状态（`BankManageView.vue:2526-2534`）。
- **可执行操作**：切换页签（roving tabindex，方向键/Home/End）；页头「练习 / 导入 / 导出 / 新建题目」。
- **操作结果**：`?tab=` 进 URL；页签计数（题目数/章节数/成员数）；加载失败按资源分别降级（章节/成员/标签/导入各自的错误态与重试，`BankManageView.vue:1108-1116`）。
- **与其他功能的关系**：题目页签 → FN-109/110/111；结构 → FN-118/119；成员 → FN-120（规则归协作域）；导入历史 → FN-121；AI 草稿 → FN-122；设置 → FN-123。
- **当前缺失与不合理之处**：标题在 bank 未加载完成时显示「加载中/加载失败」的回退链已修复（§10.4）；六个页签仍整页拉取主数据 + 次要资源并行，弱网下首屏偏重，但失败已按资源隔离，可接受。
- **理想完成态**：保持单工作区；页头主操作只有「练习」，编辑类动作（新建题目）为次级；「导出」跳到设置页导出面板并聚焦（现状如此，`BankManageView.vue:2053-2061`）。

### FN-109 题目列表与检索
- **存在目的与场景**：在工作区内浏览、筛选、排序、分页题目，是内容维护的主现场。
- **入口与适用条件**：工作区默认页签；任何成员可见（成员无编辑控件）。
- **可执行操作**：关键词（题干/题号短码/标签）、题型、章节、难度、标签筛选；排序（默认/编号/难度/更新时间）；分页（25/50/75/100，页大小存 localStorage）；「显示已归档」切换；「全选当前筛选结果」（勾选后切换筛选、翻页、改搜索**不清空已选**，CR-27）。
- **操作结果**：全部筛选/排序/页码进 URL（`?q=&type=&difficulty=&tag=&chapter=&sort=&page=&archived=`，默认值不写地址），刷新/后退/粘贴链接复现同一现场；筛选 facet 消失时自动清理（章节请求失败时不清理，`BankManageView.vue:1489-1497`）。
- **与其他功能的关系**：行题干链接 → FN-116 题目页；行「编辑/查看」→ FN-112；行归档按钮 → FN-117；勾选 → FN-110。
- **当前缺失与不合理之处**：筛选为客户端内存计算（明确非目标：服务端分页）；千题级题库下每次归档切换都全量拉取（`listBankQuestionsContent` 无分页参数）。
- **理想完成态**：保持客户端筛选；为 `content/questions` 增加服务端分页参数作为后续优化（不改变前端契约）。

### FN-110 题目批量维护
- **存在目的与场景**：对多道题一次性设置/清空章节、添加/移除标签、移动到其他题库、复制到其他题库、归档/恢复。
- **入口与适用条件**：勾选题目后出现批量条；仅编辑者及以上。选择集按题目 id 独立记住，与筛选/分页/搜索解耦（OP-102、CR-27）；批量条常驻显示「已选 N · M 项不可见」。
- **可执行操作**：选章节应用/清空；输入标签添加/移除；选目标库移动/复制；归档所选/恢复所选（恢复只作用于已归档行，`BankManageView.vue:1555-1576`）；执行前确认对话框列明**实际将受影响的题目数与范围**（含不可见项数量）。
- **操作结果**：`POST /banks/{id}/questions/batch` 单事务；整批校验（无权编辑、不属于本库、目标章节不属于本库、已归档题参与章节/标签/移动/复制）任一失败整批拒绝、无部分写入——这是 CR-27 允许的「不做」分支，但拒绝原因必须可读；单次上限 500；每次写审计 `BANK_QUESTIONS_BATCH`（含完整 question_ids）；执行结果按「成功 X / 跳过 Y」报告，跳过的必须给原因（已归档、已被他人删除、无权限）。
- **与其他功能的关系**：复制 → BR-102 新实体；移动 → BR-103；归档 → FN-117。
- **当前缺失与不合理之处**：批量章节/标签修改只 UPDATE 当前 `question_versions`，不生成新版本，痕迹只在审计日志（`question_repository.py:419-447`）——**Q-103 裁定 B：保持只写当前版本 + 审计日志，不生成题目版本**。
- **理想完成态**：保持整批原子与 500 上限；批量元数据修改在工作区显式标注「元数据修改，不产生新版本」，使「这道题的章节什么时候被改的」可从审计日志回答；选择集保留与确认对话框的影响范围按 CR-27 说清。

### FN-111 新建题目
- **存在目的与场景**：手动录入一道题，形成 v1。
- **入口与适用条件**：工作区页头「新建题目」、题目页签空态；编辑者及以上。
- **可执行操作**：填题干、题型（单选/多选/判断/填空/主观）、难度（1–5 或未分级）、章节、选项（键+文字，可增删，判断固定 T/F）、答案、标签、官方解析；保存或取消（未保存有确认）。

- **操作结果**：保存写审计并广播外壳刷新；归档 → FN-106；空库物理删除 → FN-106；导出 → FN-107。
- **与其他功能的关系**：汇集 FN-103/106/107 + 审计展示。
- **当前缺失与不合理之处**：无「删除题库」入口——Q-101 裁定 B 后仅空库可物理删除，本期需补该入口；「你的权限/锁定状态」是只读 kv，与成员页信息重复但可接受（一屏内自足）。
- **理想完成态**：保持四块结构；危险区两块动作的边界固定——「归档题库」只需一个对话框（标题带库名，**不要求输入库名**）；「删除题库」仅空库可用且**必须输入库名确认**（CR-03、Q-101 裁定 B）。

### FN-124 导入：来源与格式
- **存在目的与场景**：把外部题目文件/粘贴文本带入题库。
- **入口与适用条件**：题库列表「导入」、工作区页头「导入」、空态「导入」、工作区「导入」页签「去导入」；只读库在选择后即禁用并给原因（`ImportView.vue:133-136,933-936`）。

- **操作结果**：进入校对步（表格/PDF）或直接到重复项步（文本无重复且预检通过时，`ImportView.vue:1724`）。
- **与其他功能的关系**：喂给 FN-125/126/127；产物是题目与版本（BR-110 同一套校验）。
- **当前缺失与不合理之处**：PDF 预检在服务端同步执行，大文件等待时间无进度反馈；纯图片 PDF/损坏文件有明确拒绝路径（SPEC §5 已满足）。
- **理想完成态**：保持格式集合不变；PDF 解析改为可取消的后台任务（与 FN-128 一致），解析中显示取消入口。

### FN-125 导入：表格字段映射
- **存在目的与场景**：XLSX/CSV 的列与题目字段对应，决定重复项计算与落库内容。
- **入口与适用条件**：表格文件预检后进入校对步。
- **可执行操作**：映射题干/答案/题型/解析/难度/标签/选项合并列/选项分隔符/各选项列；查看样例行（含「与题库重复」标记）；缺题干或答案列时给出缺失提示。
- **操作结果**：离开校对步时按用户当前映射重新预检（重复项是「文件 + 映射 + 当前题库」的函数，`ImportView.vue:1731-1739`）；映射随草稿保存。
- **与其他功能的关系**：映射结果直接决定 FN-127 的重复列表。
- **当前缺失与不合理之处**：自动识别与手动映射的切换没有「恢复自动识别」一键操作。
- **理想完成态**：提供「恢复自动识别」；样例行数量可配置（默认 5 行够用）。

### FN-126 导入：PDF 预检与人工校正
- **存在目的与场景**：PDF 文本提取后结构不确定，必须人工校正再入库。
- **入口与适用条件**：PDF 文件预检成功（有候选）后进入校对步；置信度 UNCERTAIN 时禁止直接入库（`pdf_importer` + SPEC §5）。
- **可执行操作**：逐候选改题型/题干/选项/答案/解析；与上一条合并、拆分、删除；为选项增删键值；待定项有可见的「不确定」原因。
- **操作结果**：确认后走同步 `pdf-confirm`（CAS 单事务，防重复提交）；写入 `import_jobs` 与题目。
- **与其他功能的关系**：是 FN-128 后台任务的例外（保持同步，P5 刻意决定）。
- **当前缺失与不合理之处**：拆分算法是启发式（按题号换行/句读/对折切分，`ImportView.vue:2142-2191`），切错时只能手工改，无「在任意位置手动断开」的精确控制。
- **理想完成态**：提供「在光标处断开」的精确拆分；校正区显示原文片段以便对照。

### FN-127 导入：重复题处理策略
- **存在目的与场景**：重复题不静默覆盖，由用户显式选择跳过/另存新题/合并。
- **入口与适用条件**：预检发现重复（与库内现有题或批内重复）后进入重复项步。
- **可执行操作**：查看重复列表（题干 + 重复原因）；选策略（跳过/新题/合并）；未选策略时「按此处理导入」禁用并说明。
- **操作结果**：策略随导入提交；`merge` 对库内重复题生成新版本、对批内重复题合并字段；`skip` 跳过；`new` 另存。
- **与其他功能的关系**：与 BR-112/113 绑定；导入提交后 409（并发新增重复）时回退到本步重选（`ImportView.vue:1945-1951`）。
- **当前缺失与不合理之处**：重复判定是「题干 + 答案」精确匹配（`import_service.py:50-52`），改一个字就不算重复——语义正确但界面上没有说明判定口径。
- **理想完成态**：在重复项步明示判定口径（「题干与标准答案都相同视为重复」）。

### FN-128 导入：后台作业、进度、取消与重试
- **存在目的与场景**：大文件导入不阻塞界面，可看进度、可取消、失败可重试。
- **入口与适用条件**：表格/文本类导入提交后进入结果步。
- **可执行操作**：看进度条与「已写/总数」；「取消导入」；失败后「重试」（回到重复项步重提交）；运行中步骤条锁定，不能回头改映射或策略。
- **操作结果**：`POST /imports/banks/{id}/jobs` 返回 202 + job_id；每 25 条一个批次事务，进度只随已提交批次前进；取消在批次边界生效；解析/格式错误直接 FAILED 带原因；完成给可对账回执（题库/题数/重复处理）。
- **与其他功能的关系**：作业记录进 FN-121；PDF 除外（FN-126）。
- **当前缺失与不合理之处**：取消后已写入的批次保留（设计正确）但回执不显示「取消时已写入 N 题」的明确数字（`imported_count` 有，界面未突出）；重启进程后运行中作业不会自动恢复（ worker 是进程内线程，重启即丢，作业行停留在 RUNNING）。
- **理想完成态**：取消回执明确「已写入 N 题，保留在库中」；服务端重启后把残留 RUNNING 作业标记为可重试的失败态，而不是永远转圈。

### FN-129 导入草稿与续做
- **存在目的与场景**：导入是长流程，中断后能从原步骤继续。
- **入口与适用条件**：导入页顶部「继续上次导入」横幅、工作区「导入」页签草稿列表；编辑者及以上。
- **可执行操作**：继续（恢复步骤/映射/PDF 校正/策略/任务状态）、删除草稿；离开页面时三选一（留下继续 / 存草稿离开 / 放弃并离开，`ImportView.vue:2067-2104`）。
- **操作结果**：`import_drafts`（OPEN/CONSUMED/DISCARDED）保存整页状态（上限 2MB，超限 413）；600ms 防抖自动保存，保存失败页内提示不静默；步骤与草稿 id 进 URL，刷新回到原步骤。
- **与其他功能的关系**：与 FN-121 共用草稿数据源；别人的草稿读不到（404 不确认存在，`import_draft_repository.py:115-117`）。
- **当前缺失与不合理之处**：OPEN 草稿永久保留、无自动清理——**Q-105 裁定 B：不做 TTL**，列表内给「N 天前」提示（GAP-120）；草稿按「我的」维度，不支持两人协作同一导入；跨设备覆盖按 CR-23 属草稿类：后写覆盖 + 覆盖时明确告知，不是静默。
- **理想完成态**：保持单用户草稿语义；**不做 TTL 自动清理**（Q-105 裁定 B：草稿是用户的续做点，自动删有丢失风险）；列表内显示「N 天前」引导手动清理；跨设备后写覆盖时必须明确告知「你的草稿已被另一设备更新，已用较新版本替换」（CR-23）。

## 3. 业务规则（BR-1xx）

- **BR-101 一题一库**：一道题只属于一个题库。违反时：迁移 23 的触发器直接阻止第二次归属（`question_repository.py:41-58`）。例外：v22 及更早的遗留重复行原样保留、不自动删除（§14.3）。与 BR-102/103 共同构成「题目身份」的基础。
- **BR-102 复制到其他题库=新题目实体**：复制必须生成新 `questions` + v1，学习状态从空白开始；入口必须提示「学习记录不会复制」。违反时：若试图复用源题目主键，触发器拒绝。例外：无。与 BR-101 是同一约束的两面。
- **BR-103 移动保留题目身份**：移动改归属、不生成新实体；章节按名称在目标库匹配，缺失则创建同名章节。违反时（目标库不可编辑/已删除）：整批拒绝。例外：无。
- **BR-104 批量维护整批校验、整批生效**：任一题无权编辑、不属于当前题库、目标章节不属于当前题库、或已归档题参与章节/标签/移动/复制，整批拒绝且不得部分写入（SPEC §2.0.1）。违反时：返回 4xx 且数据库无任何变化（单事务 + 先校验后写入，`question_repository.py:372-417`），**拒绝原因必须可读**（CR-27：要么全做并说清数量，要么不做并说清原因）。例外：归档/恢复操作本身允许已归档题参与；被进行中模考引用的题**不阻断**批量操作，但确认对话框须提示引用场数（CR-26）。
- **BR-105 批量规模上限**：题目批量单次最多 500；题库批量单次最多 200。违反时：直接拒绝并提示上限。例外：无。
- **BR-106 题目归档语义**：归档=库内隐藏、可恢复、不删除；`archived_at` 记录时间。违反时（对已归档题执行编辑/批量元数据）：拒绝并要求先恢复。例外：恢复操作本身。
- **BR-107 归档约束**：归档题默认从内容列表、普通刷题、专项集合隐藏；用户可显式查看并恢复；归档期间不可编辑、不参与章节/标签/移动/复制。违反时：后端 400/403 + 前端禁用并给原因。例外：显式「显示已归档」视图；恢复操作本身。**原「模考锁定题的恢复仍可用」例外随锁制作废**（CR-26）。
- **BR-108 标准答案与官方解析变更必须生成新版本**：题干、选项、标准答案或官方解析任一变化都产生 `v(N+1)`。违反时：无路径可原地改内容（所有写入口都走 `create_next_version` 或批量落新版本）。例外：章节/标签等元数据批量修改不生成版本，痕迹只在审计日志（**Q-103 裁定 B**：元数据变更频率高、版本噪声大，审计日志已满足「谁在何时改了哪些题的章节」；对此需在工作区显式标注「元数据修改，不产生新版本」）。
- **BR-109 历史作答绑定原版本**：作答记录绑定 `question_version_id`；答案修改后历史作答仍按原版本解释。违反时：不可能—— Schema 层面作答指向版本而非题目。例外：无。**本期不提供历史重判**（CR-25、FN-113）：修改标准答案只影响之后开始的会话，历史成绩报告不重算、不覆盖；报告页给「查看该题当前版本」入口让用户自行判断差异。
- **BR-110 题型与答案不变量**：单选/多选至少 2 个选项且答案键必须存在；单选恰好 1 个答案；多选至少 2 个不同答案；判断答案归一为 T/F；填空/主观答案为文本。违反时：400 + 可读原因，不产生版本（`validators.py:34-134`）。例外：主观题不承诺自动评分（SPEC §5.1）。
- **BR-111 官方解析与解释版本分离**：本域的「解析」字段=官方解析（题库内容）；AI/联网/用户解释是另外的解释版本，不覆盖官方解析，也不改标准答案（SPEC §2.2）。违反时：无写入路径（解释版本归资料域）。例外：无标准答案时，AI/资料结果只能作为候选答案，用户确认后成为「个人采用答案」，不得冒充官方答案。
- **BR-112 重复题必须先预检、后策略**：发现重复必须先返回重复项，只有用户明确选择 skip/new/merge 才允许落盘（SPEC §5）。违反时：409 带重复清单，无任何写入。例外：批内重复按首现索引合并，不伪造数据库 ID。
- **BR-113 导入预检失败不得落盘、单事务**：解析失败/映射缺失/校验失败直接终态，不产生题目；批量写入单一事务，中途失败整批回滚（护栏文档）。违反时：作业标记 PRECHECK_FAILED/FAILED 并带原因。例外：后台任务按已提交批次前进（取消时保留已写入部分，这是显式设计）。
- **BR-114 PDF 低置信度必须人工校正**：能提取文本但结构不确定 → 校对草稿；纯图片/损坏/结构不可确认 → 直接拒绝并说明，不静默入库、不自动 OCR（SPEC §5）。违反时：上传即拒。例外：无。
- **BR-115 标签双源、实体权威**：`knowledge_tags`+`question_tag_items` 是当前标签的唯一权威；`question_versions.tags_json` 是不可变历史快照。违反时：无——重命名走实体，历史快照不改写。例外：题库从未产生过标签关联时（`has_links=false`）回退读快照，保证旧数据可显示。
- **BR-116 章节归属题库**：章节只能挂到本库题目；批量设章节时目标章节必须属于当前题库；移动时按名匹配/创建。违反时：整批拒绝。例外：无。
- **BR-117 进行中模考不锁定题库内容**：模考会话在开考时持有题目与版本快照（模考域 `BR-309`），编辑、归档、批量维护题库内容**不阻断、不锁定**（CR-26）。违反时：不得以「模考进行中」为由拒绝编辑或归档；超时也不解除任何锁定，因为本来就没有锁定。例外：编辑者归档/删除已被进行中模考引用的题目时，执行前必须提示「有 N 场进行中的模考引用本题；这些考试仍按快照进行，新考试将不再包含本题」，确认后执行。原「禁编辑/禁归档/禁批量元数据 + 读接口脱敏答案与解析 + 60 秒超时缓冲」的口径全部作废。
- **BR-118 题库归档与进行中模考不互斥**：题库有进行中模考时**可以**归档（CR-26：锁定的协作阻塞远大于其防护价值）。归档提示须写明「N 场进行中的模考仍按快照完成；归档后新考试不能再选这个题库」。违反时（现状违反）：`banks.py:146-151` 以进行中模考为由拒绝归档。例外：无。
- **BR-119 审计留痕**：每次批量维护、成员变更、章节/标签变更、版本删除都必须留下可审计记录（SPEC §2.0.1）。违反时：无——所有写路径都插 `audit_logs`。例外：审计仅所有者可见（PR-105）。
- **BR-120 导入写入权限**：导入（含草稿、作业）需要编辑者及以上；成员只读。违反时：403 且在向导第一步就禁用「下一步」并给原因。例外：无。
- **BR-121 导出范围默认不含归档**：导出默认只含在用题目，可显式勾选包含已归档。违反时：无。例外：无。
- **BR-122 「题库内容量」与「我的可练题量」是两个数；可练量为 0 不得生成会话**：**题库内容量** = 该库全部未归档题目数，公共语义，所有成员看到同一个数，斩杀不影响它；**我的可练题量** = 内容量 − 归档 − 我斩杀的，个人语义。卡片与列表统一显示「共 N 题 · 我可练 M 题」；只有**我的可练题量为 0** 时「开始练习」禁用并解释（CR-04）。违反时：①不得用内容量充当可练量，不得因个人斩杀改变公共内容语义；②库内内容量 > 0 但可练池为 0（全部被斩杀/归档耗尽）时仍生成 0 题会话（GAP-102，本期修复）。例外：显式 `question_ids` 的专项模式本就要求集合约束（学习域规则）。
- **BR-123 删除标签不得级联删除个人资料**：标签删除只解除关联；关联到该标签的个人笔记/总结/口诀必须保留（**Q-108 裁定 A：解绑 SET NULL，不得删除用户笔记，这是数据丢失红线**）。违反时（现状违反）：`ON DELETE CASCADE` 静默删资料（GAP-103）。例外：无。

### 3.1 操作与交互规则（OP-1xx）

- **OP-101 唯一进入入口**：进入题库的入口只有列表行名称；进入题目的入口只有行内题干链接（与面包屑）。行内只放行级动作（编辑/查看、归档、菜单）；菜单项对无权限者禁用并带可读原因；Esc 关闭菜单且焦点回到触发按钮。
- **OP-102 批量条与选择集（CR-27）**：勾选后才出现批量条，空选中不占版面。选择集是**按题目 id 记住的独立集合**，与筛选/分页/搜索解耦：①切换筛选、翻页、改搜索**不清空已选**；②批量条常驻显示「已选 N」，其中含「M 项当前不可见」时明确标出「已选 N · M 项不可见」；③允许对不可见项执行操作（用户显式勾过），但执行前确认对话框必须列出**实际将受影响的题目数与范围**（含不可见项的数量）；④**不得按可见行修剪后静默少做**——要么全做并说清数量，要么不做；⑤执行结果按「成功 X / 跳过 Y」报告，跳过的必须给原因（已归档、已被他人删除、无权限），不静默；⑥归档/恢复各自只作用于能改变状态的行，成功提示不得虚报；⑦选中含被进行中模考引用的题时不阻断，确认对话框须提示引用场数（CR-26）。
- **OP-103 工作区 URL 契约**：`?tab=&q=&type=&difficulty=&tag=&chapter=&sort=&page=&archived=`；默认值不写地址；地址↔控件双向同步（后退、粘贴、刷新都复现同一现场）；`pageSize` 是设备偏好存 localStorage，不进 URL。
- **OP-104 题目页深链与版本预览**：题目页可深链/刷新/分享；`?v=` 进入旧版预览，刷新与后退可复现；预览态隐藏编辑/练习/归档并显示「回到当前版」；题库与题目不匹配时重定向到正确题库而非报错。
- **OP-105 导入向导步骤与 URL**：`?bankId=&step=&draft=&from=`；步骤可达性由数据校验决定（没有预览不能进校对/重复项，没有作业不能进结果）；离开校对步按用户当前映射重新预检；运行中作业锁定步骤条，只能取消不能回头。
- **OP-106 弹窗与取消路径**：每个表单/确认弹窗必须同时有「确认」与「取消/关闭」两条出口；Esc 与遮罩点击等于取消；危险动作用危险样式且初始焦点在取消；取消路径不得产生任何写入（含不得改 URL 状态）。
- **OP-107 离开守卫与未保存保护**：有未保存修改时，关闭弹窗先问「丢弃这次编辑？」（继续编辑/丢弃并关闭）；导入离开时三选一（留下/存草稿离开/放弃并离开）；运行中导入作业离开不拦截（任务在服务端继续，工作区导入页签可见状态）。
- **OP-108 请求竞态防护**：列表/题库/题目/版本请求使用单调序号，只有最新请求能写状态；归档视图切换与整页加载用不同序号，避免旧响应的 `finally` 清掉新状态的 loading；目标库变更时在飞请求一律丢弃。
- **OP-109 错误出口分级**：行内操作错误（批量、保存、单题归档）留在原处并给重试；次要资源（章节/成员/标签/导入记录/草稿）独立错误态 + 重试，绝不塌成「空列表」；整页加载失败才升级为整页状态（可重试）；403/404 走整页权限状态，其他失败保持页内 notice。
- **OP-110 成功后落点与刷新**：建库后进入新库工作区；导入完成「查看题库」落到接受任务的库（不是选择器当前值）；开始练习统一走学习域开始入口（先决策活跃会话）；保存题目后工作区局部更新该行、题目页整页重载；题库资料/成员变更后广播刷新外壳缓存。

## 4. 数据关系与状态变化

### 4.1 实体关系

```text
question_banks 1──N chapters（库内树，parent_id 自引用）
question_banks 1──N knowledge_tags
question_banks 1──1 bank_question_items 1──1 questions 1──N question_versions
question_versions N──N knowledge_tags（经 question_tag_items）
questions 1──1 bank_question_items（1:1，迁移 23 触发器保证）
question_banks 1──N import_jobs / import_drafts / pdf_import_drafts
questions 1──N question_conflicts（未决冲突）
audit_logs（entity_type='BANK' | 'QUESTION'）
```

学习域事实表（`fsrs_cards`/`mistake_records`/`kill_records`/`learning_records`）主键为 `(user_id, question_id)`，**没有 bank 维度**——本域只负责保证「题目有唯一归属」，不负责把学习状态按库拆分（UX §7.6 明确不改三维主键）。

### 4.2 生命周期

| 对象 | 创建 | 变更 | 归档/隐藏 | 恢复 | 删除 |
|---|---|---|---|---|---|
| 题库 | 建库（所有者自动入成员表） | 资料更新、分类改写 | `is_deleted=1`（=归档，命名债见 GAP-121） | `is_deleted=0` | 仅空库可物理删除，须输入库名确认（CR-03、Q-101 裁定 B） |
| 题目 | 手动/导入/复制/草稿采纳 | 编辑生成新版本；批量元数据原地改 | `is_deleted=1` + `archived_at` | 同上传恢复 | 无物理删除（保留作答外键） |
| 题目版本 | v1 随题目创建 | 每次内容变更 v(N+1) | — | — | 可删非当前且无作答引用的版本 |
| 章节 | 新建（根/子） | 重命名/改父级/重排 | — | — | 删除（子章节提升到父级） |
| 标签 | 新建/导入时自动建 | 重命名（撞名=合并） | — | — | 删除（解除关联，快照不动） |
| 导入作业 | 提交导入 | 状态推进 + 批次进度 | — | — | 不删（历史） |
| 导入草稿 | 进入向导即建 | 600ms 防抖自动存 | — | — | 硬删除（一次性 scratch） |

### 4.3 关键状态机

**题库（ST-101）**：`在用 → 已归档 → 在用`；`在用 → 已删除`（仅空库，输入库名确认）。进行中模考**不**阻断归档（CR-26）。异常转换：非所有者任何转换 403；不存在 id 404；非空库的物理删除被拒并说明原因。

**题目（ST-102）**：

| 状态 | 进入条件 | 可做什么 | 禁什么 |
|---|---|---|---|
| 在用 | 创建/恢复 | 编辑、批量维护、练习池可见 | — |
| 已归档 | 归档操作 | 查看（显式视图）、恢复 | 编辑、批量章节/标签/移动/复制 |

异常转换：对已归档题编辑 → 400「须先恢复」。

**原「模考锁定」状态已取消**（CR-26）：会话持快照，题目页答案与解析正常可见，编辑/归档/批量均不被进行中模考阻断；被引用题的归档只在确认对话框里给一句引用场数提示。

**题目版本（ST-103）**：`当前 → 历史`（新版本产生时）；`历史 → 已删除`（仅无作答引用且非当前）；`冲突未决 → 已解决`（采用某版本生成新版本）。异常转换：删当前版本 → 400；删被引用版本 → 400。

**导入作业（ST-104）**：`PENDING/RUNNING → COMPLETED | FAILED | PRECHECK_FAILED | CANCELLED`（另有一个旧同步导入路径的成功终态 `IMPORTED`，与 `70` 册 §3 一致；新代码走 `COMPLETED`）；进度只随已提交批次前进；终态不可再变（`finish_async` 的 `WHERE status='RUNNING'` 保证）。异常转换：取消请求在批次边界生效；重启后残留 RUNNING 无自动恢复（GAP-123）。

**导入草稿（ST-105）**：`OPEN → CONSUMED | DISCARDED`；OPEN 永久保留直到用户删除，**不做 TTL 自动清理**（Q-105 裁定 B），列表内给「N 天前」提示；读他人草稿=404；跨设备后写覆盖时必须明确告知（CR-23）。

## 5. 权限规则（PR-1xx）

- **PR-101 题库角色能力矩阵**（角色定义归协作与实例域，此处只列本域操作；表达方式按 CR-12 分流）：

| 操作 | 所有者 | 编辑者 | 成员 |
|---|---|---|---|
| 浏览题目/工作区各页签 | ✓ | ✓ | ✓ |
| 新建/编辑题目、批量维护、归档恢复 | ✓ | ✓ | ✕（禁用 + 原因） |
| 导入（含草稿、作业） | ✓ | ✓ | ✕（禁用 + 原因） |
| 章节/标签管理 | ✓ | ✓ | ✕（禁用 + 只读） |
| 改资料、归档题库、删除空库、审计 | ✓ | ✕（禁用 + 原因） | 不显示 |
| 管理成员（增/改角色/移除/转移所有权） | ✓ | ✕（可见名单与自己的角色） | ✕（可见名单与自己的角色） |
| 导出 | ✓ | ✓ | ✓ |

- **PR-102 角色只改变能力，不改变结构**：成员进入工作区看到同样的六个页签与同样的题目列表，只是编辑类控件不渲染/禁用；不存在「只读详情页 vs 可写管理页」的两套页面（P2 已合并，`/banks/:id/manage` 仅重定向）。
- **PR-103 越权与不可见的表达**：非成员访问题库/题目 → 整页 403/404 状态（「你不在这个题库里 / 这个题库不存在」+ 返回列表），不是后端英文报错、不是隐藏入口后报错；后端对所有数据接口独立兜底（成员校验 + 角色校验，ADV2-002 已修复成员可改题目的越权）。
- **PR-104 实例角色与题库角色分离**：同一个「管理员」在账户菜单/设置页指实例角色，在工作区内只显示「你在本题库的角色」；本域不得把题库角色呈现为系统角色。
- **PR-105 审计与导入作业的可见范围**：管理日志仅所有者；导入作业记录对库内任何成员可见（共享透明度），但他人草稿不可见、他人作业详情不可绕权读取（`import_service.py:472-477`）。

## 6. 跨域与跨页联动

- **→ 学习域（开始练习）**：题库列表行「开始练习」、工作区页头「练习」、题目页「练习这道题」都走同一个开始入口：先查同模式活跃会话，有则弹「继续 / 结束并新建 / 取消」，无则直接开始。只有**我的可练题量为 0** 时「开始练习」禁用并解释，后端无条件拒绝 0 题会话（BR-122、CR-04；现状违反见 GAP-102）。
- **→ 学习域（斩杀可见性）**：斩杀题在内容管理（FN-109）中仍可见可维护，但从练习池排除；斩杀不影响题库内容量、只影响我的可练题量（CR-04）；GAP-108 的口径收敛按该条落地。
- **→ 模考域（快照）**：进行中模考**不锁定**题库内容（CR-26）：编辑/归档/批量均不阻断，答案解析不脱敏；被引用题被归档/移动/复制时，确认对话框提示「N 场进行中的模考引用本题；这些考试仍按快照进行，新考试将不再包含本题」；超时不解除任何锁定（本来就没有锁定），只结束作答窗口。
- **→ 协作域**：角色决定 PR-101 矩阵；成员页签的内容规则归协作域；共享库在列表独立分段并带角色徽章。
- **→ 资料域**：AI 草稿箱（FN-122）与「AI 设置」跳转（`/settings?section=ai`）；题目页缺少笔记/资料关联入口（GAP-122）。
- **不同进入路径的差异**：
  - 导入入口有四（列表页头、工作区页头、工作区导入页签、空态）；从列表/空态进入无 bank 预设，从工作区进入带 `?bankId=`；完成后「查看题库」落到接受任务的库（不是选择器当前值，`ImportView.vue:2112-2121`）。
  - 题目页可从工作区行链接、复习/错题行、分享深链进入；从复习进入时面包屑仍是「题库 / 题库名 / 第 N 题」（题库上下文不丢）。
- **不同操作顺序的差异**：
  - 先编辑后归档 vs 先归档后编辑：后者被拒并要求先恢复（BR-106/107）。
  - 批量操作中混选已归档行：归档/恢复各自只作用于能改变状态的行，成功提示不虚报，并按「成功 X / 跳过 Y」报告、跳过必须给原因（CR-27）；混选当前不可见项时，确认对话框列明实际将受影响的题目数与范围。
  - 导入中改目标库：有预览/映射时弹确认，接受即丢弃旧草稿重来（`ImportView.vue:1547-1580`）；运行中作业期间选择器锁定。
  - 编辑保存后工作区局部更新该行（`handleQuestionSaved`），题目页整页重载——同一操作两种刷新策略，均可接受但应保证版本号显示同步。

## 9. 问题裁定记录（Q-1xx）

> 本册全部 Q 项均已裁定（**0 条待用户裁**）。每条给出最终结论与正文落点；裁定前的候选与推荐不再具有权威性（00 册 §10）。

- **Q-101 题库是否支持物理删除**（**已裁定 B**）：只做归档——`DELETE /banks/{id}` 对外术语一律称「归档题库」，确认框只需一个对话框、不要求输入库名；物理删除仅限**空库**（无任何题目且无任何作答引用）且必须输入库名确认。术语「删除」只保留给空库这一种情形（CR-03）。正文见 FN-106 / FN-123 / ST-101。
- **Q-102 斩杀题是否计入题库题量**（**已裁定 B**，按 R16 落地）：斩杀**不影响题库内容量**（公共语义），只影响**我的可练题量**（个人语义）；卡片与列表统一显示「共 N 题 · 我可练 M 题」，只有可练量为 0 时「开始练习」禁用并解释（CR-04）。正文见 BR-122 / FN-101 / FN-109。
- **Q-103 批量章节/标签修改是否生成题目版本**（**已裁定 B**）：只写当前版本 + 审计日志，不生成题目版本；审计日志已满足「谁在何时改了哪些题的章节」，工作区需显式标注「元数据修改，不产生新版本」。正文见 BR-108 / FN-110。
- **Q-104 是否提供「回滚到历史版本」**（**已裁定 B**）：不提供。需要旧版内容时通过编辑实现，或走 FN-115 冲突解决的「采用某版本 → 生成新版本」路径；避免「回滚」被误用为覆盖他人工作。正文见 FN-114。
- **Q-105 导入草稿是否加过期清理**（**已裁定 B**）：永久保留、不自动清理、无 TTL；列表内给「N 天前」提示引导手动清理——草稿是用户的续做点，自动删有丢失风险。正文见 FN-129 / ST-105。
- **Q-106 已归档题库是否提供批量恢复**（**已裁定 B**）：保持单行恢复，不做批量恢复——归档多个库是更可能的批量动作，恢复通常逐个确认。正文见 FN-101 / FN-105。
- **Q-107 导出是否包含版本历史与学习统计**（**已裁定 A**）：只导当前内容（在用题目，可选包含已归档），不含版本历史、不含任何学习统计——导出定位是内容备份，学习统计属个人学习档案，混入会扩大分享面。正文见 FN-107。
- **Q-108 标签删除时关联资料的处理方式**（**已裁定 A**）：删除标签时关联资料解绑（SET NULL）并保留，**不得静默删除用户笔记**——这是数据丢失红线。正文见 BR-123 / FN-119。
