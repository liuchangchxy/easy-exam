## 2. 跨域规则裁决

### CR-01 一道题只属于一个题库（已确认，落地）
复制到其他题库 = **生成新题目实体与初始版本**，学习状态从空白开始；移动 = **保留题目身份、更换归属**。存储层已由触发器强制（迁移 23，`trg_bank_question_single_bank`）。
→ 细则见 `BR-1xx`。**遗留的历史重复行不自动删除**，只拦新写入（UX §14.3）。

### CR-02 学习状态挂在题目上，不挂「题目 × 题库」
`fsrs_cards` / `mistake_records` / `learning_records` / `weak_question_flags` / `kill_records` 主键均为 `(user_id, question_id)`。因为 CR-01 已保证一题一库，`(user, question)` 与 `(user, question, bank)` 等价，**不改成三维主键**（UX §7.6 明确不建议）。
**但用户界面的单位是「这个库里的这道题」**：所有面向用户的列表、统计、越权提示，必须以题库为上下文呈现；退出题库后不得让历史从统计里消失（`mistake_records.bank_id` 为冗余展示字段，不是归属字段）。

### CR-03 归档 ≠ 删除
`questions.archived_at`（迁移 19）承担「库内归档」语义，可恢复；`is_deleted` 仍是归档位（行为等价，命名债记入 DECISIONS）。
- 归档题目：默认从题库内容列表、普通刷题、专项集合、统计中隐藏；可在工作区 `?archived=1` 显式查看并恢复。
- 归档期间：不可编辑，不参与章节/标签/移动/复制等批量维护。
- **题目没有「回收站」这个概念**——归档不是删除。删除题目仅在没有作答引用时可行。
- 题库的「删除」按钮（`DELETE /banks/{id}` 实为归档）：**现状**只需一个确认对话框（标题带库名，`BanksView.vue:836-843`），**不要求输入库名**。若 `Q-101` 裁定实现真删除，则必须输入库名确认且仅在无进行中考试时可用。要求输入库名的是**转移所有权**（`BankManageView.vue:799-827`），不要与题库归档混淆。

### CR-04 可见性三套口径必须统一表述
历史上三处 SQL 口径不同（卡片计数不含归档含斩杀 / 练习池不含归档不含斩杀 / 内容管理含斩杀、归档可选）。
**裁决**：这不是三个口径，而是**三个视图**，允许不同；但必须在文档中固定每个视图的包含集合，且同一道题在三处的出现/消失必须可由用户理解（工作区给出「已归档 N / 已斩杀 N」计数作为出口）。

### CR-05 「到期」的唯一定义（**待 `Q-204` 裁定，此处只记现状**）
**现状** = `list_due_reviews` 口径：要求「有未清除错题**或**有薄弱标记」，纯 FSRS 到期卡不出现。而 `trends.due` 同此口径，`recommendation_candidates.is_due` 却只看 `due_at`——三套 SQL 口径互斥（`practice_repository.py:936-939` vs `:1034-1036` vs `:1126-1129`），已登记为 `GAP-209`。
**理想态（推荐，见 `Q-204`）**：到期 = `due_at <= now 且未斩杀`，错题/薄弱/巩固作为叠加原因标签。
FSRS 只调度错题与 `mark_weak` 题，不默认调度所有做过的题（SPEC §4.2）。
→ 细则见 `BR-2xx`；服务端对 `question_ids` 做集合约束，严禁客户端伪造筛选退化为整本普通刷题。
> ⚠️ 本册其他 CR 条目都是已裁定规则；**CR-05 是唯一一条「未裁定」的**，实施前必须先裁 `Q-204`。

### CR-06 判分三要素不可互相替代
`score_ratio`（得分比）/ `correctness`（是否完全正确）/ `mastery_status`（是否已掌握）三者分离。
- 多选漏选可得部分得分，但**不得**视为完全正确、不得视为已掌握、不得触发错题出库。
- 部分得分**不得**直接映射为 Good 评级。

### CR-07 会话状态必须三分
`practice_sessions` 历史上只有一个 `is_completed`，完成与放弃同值。
**裁决**：会话状态必须是 `active` / `completed` / `abandoned` 三态，`score` 与 `time_spent` 必须落值，报告必须落库并可回看（`/sessions/:id/report`）。
- 已交卷、已取消或其他终结态的会话**必须拒绝任何后续作答提交**。
- 提交与交卷必须幂等：网络重试不得重复插入作答、重复计入错题或重复推进 FSRS。

### CR-08 模考错题是否进入复习由考试配置决定，默认进入
`record_mistakes` 为真时，交卷判分同样写 FSRS 卡（与 SPEC §4.1「由考试配置决定」一致；UX 决策 6 定为默认进入）。为假时错题只留在错题表，不进 FSRS。

### CR-09 斩杀只能用户主动执行
系统不得自动斩杀。斩杀题从普通刷题、错题复习和 FSRS 队列移出，进入斩杀题库；**答错后恢复为未斩杀**并重新进入相应复习流程；**不因时间自动恢复**。
斩杀题列表必须透传 `bank_id` 上下文，服务端在 ELIMINATION 模式下校验题目属于已斩杀集合。

### CR-10 标准答案与解释分离
标准答案属于题库内容，修改必须生成新版本，历史作答绑定原版本。官方 / AI / 联网(WEB) / 用户 四类解释是不同来源的解释版本，**任何一类都不得覆盖另一类**；用户可选定主解释；AI/联网/用户解释都不得自动改写标准答案。
题目没有标准答案时，AI/资料/联网结果只能作为「候选答案」，用户确认后成为个人采用答案，仍不得冒充官方答案。

### CR-11 两层角色，两套词
**实例角色**：管理员 / 普通用户。**题库角色**：所有者 / 编辑者 / 成员。
不得用同一个「管理员」同时指两者。账户菜单与设置显示实例角色；题库内只显示「你在本题库的角色」。

### CR-12 权限改变能力，不改变结构
无编辑权时**禁用并解释**，不隐藏入口；非成员访问题库给 403 页；后端 403 必须转成用户可理解的呈现，不得把英文错误码或顶部 banner 当作唯一反馈。
同一角色在不同页面必须表现一致（历史上存在 隐藏/禁用/banner 三套语义）。

### CR-13 学习记录私有
每个用户的作答、错题、AI 解释、斩杀状态、复习计划、资料必须私有。共享题库只共享内容，不共享学习记录。多用户之间无法读取彼此的学习记录。

### CR-14 开始学习只有一个决策点
所有「开始练习 / 开始复习 / 开始模考」入口调用同一个开始决策；参数完整时直接开始，否则打开开始面板；**已存在同模式未完成会话时统一提示「继续 / 结束并新建 / 取消」**，取消不新建会话。

### CR-15 返回就是历史
不声明静态父子关系。返回先回退应用内历史，无历史时走页面声明的 fallback。全屏 runner 与普通页面使用同一套返回模型。

### CR-16 状态进 URL
凡用户调整过、希望回来还在的状态（筛选、排序、页码、tab、选中、题目、向导步骤、草稿 id）都进 URL；默认值不写地址。设备级偏好（每页条数）留 localStorage。

### CR-17 一个实体一个规范页面
题库工作区一个页面（题目/结构/成员/导入历史/AI 草稿/设置）；题目页替代抽屉；`/banks/:id/manage` 仅为 redirect；实例管理是独立路由（实例级权限），不是设置的 tab。

### CR-18 资料与笔记是辅助，不是主线
笔记 / AI 总结 / 口诀 / 上传文件是题目与知识点的辅助材料，**不生成独立 FSRS 任务，不改变刷题主线**，不做成独立背卡产品。

### CR-19 AI 是横向能力，不是产品
没有 AI 时核心功能完整可用。AI 不提供无题目上下文的独立聊天主入口。AI 可建议标签、蓝图、变式题，但均需用户确认；AI 变式题先作草稿，不直接进入共享正式题库。

### CR-20 导入必须可续做、可对账
导入是向导（来源 → 校对 → 重复项 → 结果），草稿落库并可续做；离开时给「稍后继续 / 放弃」两个明确出口；重复项属于（文件 + 映射 + 当前题库）三者的函数，必须由用户显式选择 `skip` / `new` / `merge` 后才写入；每次导入留 `import_jobs` 审计记录；预检失败不得落盘。

### CR-21 无复杂配置也要可用
未配置 AI、联网搜索或本地资料时，题库导入、普通刷题、模考、错题、趋势、计划、FSRS、斩杀题库均正常工作。未配置蓝图、章节权重或知识点树时，使用基础题库模式，仍可按题型、标签、历史正确率和复习状态工作。

### CR-22 难度筛选只依据标注
只依据题目明确标注的 1–5 级难度；未标注视为「未分级」：未启用具体难度筛选时可参与推荐，启用后排除。**不得依据用户作答数据推断题目难度，不得跨用户聚合答题表现。**

### CR-23 跨设备合并不静默丢版本
同一用户的多设备修改按服务端事件顺序合并；无法自动合并时保留两个版本并提示用户选择。改密时吊销其他会话。

### CR-24 一次作答同事务更新
`mistake_records`（用户级错题事实）与 `learning_records`（掌握状态与统计）必须在同一事务内更新。导入必须创建 `import_jobs` 审计记录，解析预检失败不得产生题目。

## 3. 关键状态机总览

> 各域完整状态机见分册 §4；此处只固定跨域共享的状态语义。

| 状态机 | 状态集 | 关键约束 |
|---|---|---|
| 题目 | `active` / `archived` / `deleted` | 归档可恢复；删除仅无作答引用时 |
| 题目版本 | `current` / `historical` | 修改标准答案必须新建版本；历史作答绑定原版本 |
| 练习会话 | `active` / `completed` / `abandoned` | 终结态拒绝作答；提交幂等 |
| 模考会话 | `active` / `completed` / `abandoned`（与练习会话同一状态集，`mode='EXAM'` 只是判分时机与是否锁题不同） | 交卷前不泄露对错；负分只在报告阶段应用；报告落库后会话为 `completed` |
| FSRS 卡片 | `new` / `learning` / `review` / `relearning` | 评级 Again/Hard/Good/Easy；两步交互与一次性评分调度等价 |
| 错题 | `open` / `cleared` | 错因可改；专项集合由服务端校验 |
| 斩杀 | `active` / `restored` | 只能用户主动斩杀；答错恢复 |
| 解释版本 | `official` / `ai` / `web` / `user` × `primary` 标记 | 互不覆盖 |
| 导入作业 | `PENDING` / `RUNNING` / `PRECHECK_FAILED` / `IMPORTED` / `COMPLETED` / `FAILED` / `CANCELLED`（`connection.py:443` 的 CHECK 全集） | 进度按已提交批次推进；可取消；不重放。`IMPORTED` 是旧同步导入路径的成功终态，`COMPLETED` 是后台作业的成功终态 |
| 导入草稿 | `OPEN` / `CONSUMED` / `DISCARDED` | 他人草稿读不到（404） |
| 用户账号 | `active` / `disabled` / `must_change_password` | 改密前拦截非豁免业务 API |
| 题库成员 | `owner` / `editor` / `member` | 重复添加不得静默改角色 |

## 4. 跨域联动矩阵

| 触发 | 影响域 | 必须发生的联动 |
|---|---|---|
| 归档一道题 | 题库 / 学习 / 统计 | 工作区列表、练习池、专项集合、统计同步排除；计数给出出口 |
| 修改标准答案 | 题库 / 学习 / 模考 | 新建版本；历史作答绑定旧版；可选历史重判（单事务） |
| 斩杀一道题 | 学习 / 统计 | 从普通刷题、错题复习、FSRS 队列移出；斩杀题库可见 |
| 错题答对并出库 | 学习 / 统计 | FSRS 推进；错题状态变更；掌握状态更新（同事务） |
| 交卷 | 模考 / 学习 | 报告落库；按 `record_mistakes` 写错题与 FSRS；会话转 `completed` |
| 添加题库成员 | 协作 / 题库 | 对方题库列表出现共享库并标注角色；越权访问立即变为可访问 |
| 禁用用户 | 协作 / 全局 | 其会话失效；学习中页不得静默失败 |
| 切换语言/主题 | 全局 / 所有域 | 全产品即时生效并持久化；题库内容与解析不翻译 |
| 导入完成 | 题库 / 学习 | 题库计数更新；练习池纳入新题；导入历史可对账 |

## 6. 跨端行为（汇总）

> 各域的端差异见分册 §7；此处固定全产品必须一致的部分。断点按**内容**定义，不按设备命名。

| 档位 | 侧栏 | 顶栏 | 底部导航 | 主体 |
|---|---|---|---|---|
| **> 1024（桌面）** | 完整（品牌 + 分组标签 + 五项 + 学习状态 + 设置） | 面包屑 + 搜索 + 主题 + 语言 + 头像 | 不显示 | 居中纸面，默认宽 1120px；资料/题库工作区可用宽版 1320px |
| **641–1024（平板）** | 收窄为图标轨 | 同上 | 显示 | 单列为主；工作区页签横向可滚动；管理表由自身容器横滚 |
| **≤ 640（移动）** | 不显示 | 移动顶栏（返回/品牌 + 页名 + 搜索 + 头像） | 显示 6 项 | 单列；列表转卡片；主操作固定底部 |

全产品统一规则：
1. **三档（375 / 768 / 1440）不得出现横向滚动**；宽表格由自己的容器滚，不撑破纸面。
2. **触屏点击目标 ≥ 44px**；无法长高的图标按钮补 44×44 命中区。
3. **软键盘弹出时底部操作条随视口上移**（`--kb-inset`），不得被遮。
4. **安全区**上下左右都处理，不只处理底部；**不禁用双指缩放**。
5. 每个动作都必须有**可见入口**；长按/滑动只作为增强，不作为唯一路径。
6. 外壳断点收敛为 **1280 / 1024 / 768 / 640** 四档；各视图残留的 scoped 旧断点见 `GAP-607`、`GAP-118`、`GAP-328`。
7. 移动端「更多」= 进入设置页（设置内含主题/语言），不做成第二层浮层菜单。

## 7. 原型与生产代码的已知不一致

> 本节是「配置与实际不一致」类 GAP 的集中登记处。**本轮只登记，不修改原型**（P1 范围）。

| # | 项 | 原型 | 生产代码 | 裁定 |
|---|---|---|---|---|
| PI-01 | 实例权限判据 | `assets/store.js:430` 把 `instance.manage` 绑在**题库角色** `OWNER` 上；`pages/screens/settings.html:1197` 把题库角色标成「实例角色 · 所有者」 | 实例角色独立于题库角色（`AppLayout.vue` 按实例角色控制 `/instance`） | **原型错**，违反 CR-11 与 `PR-401`；应按实例角色判定 |
