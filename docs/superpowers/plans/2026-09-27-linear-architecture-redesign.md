# EasyExam 前端重构实施计划：架构 1（Linear 极客指令流）

> 日期: 2026-09-27  
> 目标: 按照用户确认的“架构 1：Linear 极客指令流”彻底重构 EasyExam 前端，建立全键盘流、发丝线紧凑排版、FSRS 实时指标侧栏及全站 Linear 极客风格规范，同时严守测试与移动端首屏物理预算。

---

## 一、设计语言与三旋钮规范 (Linear Spec)

1. **三旋钮参数**：
   - `DESIGN_VARIANCE`: 3（极致整洁、发丝线对称网格、纯正工程工具感）
   - `MOTION_INTENSITY`: 2（极速即时响应，100ms 触觉微反馈，0 拖沓长动画）
   - `VISUAL_DENSITY`: 8（紧凑效率座舱，消除一切卡片套卡片的冗余边距，首屏看全题干与选项）
2. **调色板与材质**：
   - 底色：深灰石墨冷黑 `--bg-canvas: #09090b; --bg-surface: #121215; --bg-subtle: #18181b;`
   - 边框：极细发丝线 `--border-hairline: #27272a; --border-focus: #3f3f46;`
   - 强调色：极客翠绿 `--brand: #10b981;` 与电青 `--brand-cyan: #06b6d4;`
   - 字体：等宽代码体（JetBrains Mono / SFMono / Consolas）作为指示器与键位一等公民，正文搭配高可读无衬线体。

---

## 二、任务分解与实施批次

### Task 1: 全站 Linear 设计令牌与基础原子层 (`frontend/src/style.css`)
- 注入 Linear CSS 变量系统（深色石墨底色、1px 发丝边框、等宽字符类、快捷键徽章标）。
- 保持既有语义类名（`.primary-btn`, `.error`, `.success` 等）向前兼容，确保现有单元测试与布局不断裂。

### Task 2: 核心刷题页 `PracticeViewV1.vue` 落地 Linear 极客指令流
1. **顶栏压平至紧凑 App Bar (≤40px)**：
   - 面包屑（题库/章节/题型）、进度比例（`Q 14/85`）、正确率指标（`ACC 85.7%`）。
2. **主体左侧发丝线题目流**：
   - 题干大字号护眼排版（17px / 行高 1.65）；
   - 选项改为纯发丝线流式行（带 `[1]`, `[2]`, `[3]`, `[4]` 等宽快捷键标，选中有翠绿高亮边与微反馈）；
   - 彻底清除多层白色浮起卡片与冗余占位框。
3. **主体右侧 FSRS 记忆力实时指标面板**：
   - 显示当前题目 FSRS 稳定性 S、难度 D、记忆可提取性 R 与下次预计复习日；
   - 答题后提供四档快捷评分按键（`[1]重来`、`[2]困难`、`[3]良好`、`[4]简单`）。
4. **底部极客键盘指令条**：
   - 明确标注 `1..4` 作答、`J/K` 切题、`Space` 展开解析、`M` 标记疑难；
   - 原生支持全套键盘监听事件，无鼠标即可极速连刷。
5. **移动端适配**：
   - 屏幕宽度 < 768px 时，右侧 FSRS 面板收敛为可展开抽屉或底部栏，确保移动端题干与选项零滚动看全。

### Task 3: 全真模考 `ExamView.vue` 与其他核心视图 Linear 化
1. **`ExamView.vue`**：
   - 顶栏精简为发丝线倒计时器与交卷控制台；
   - 答题卡矩阵以等宽紧凑方块呈现，未答/已答/标记一眼尽览；
   - 交卷后成绩单报告采用 Linear 数据看板排版，消除白屏空洞。
2. **`HomeView.vue`、`LearningView.vue`、`MistakesView.vue`**：
   - 统一顶栏高度（≤44px，满足 AGENTS 避坑第 10 条）；
   - 题库卡片与指标面板采用 Linear 发丝线网格（Hairline Grid）。

## 三、测试与质量门禁

1. 运行 `npm run test`（11 个前端单元测试确保全绿）。
2. 运行 `npm run build`（确保 Vite 打包零报错，产物哈希更新）。
3. 运行 Chrome 浏览器 E2E 真实走查（`npm run test:e2e` 或专用验证脚本），验证刷题、交卷、快捷键与流转。
