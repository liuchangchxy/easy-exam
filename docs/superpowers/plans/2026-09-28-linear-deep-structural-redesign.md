# Linear 深度架构重构实施方案 (Linear Deep Structural Redesign)

## 目标与重构背景

前期前端改造主要集中在 CSS 变量暗色化、发丝线注入和局部快捷键绑定，但页面底层的 DOM 骨架、宏观信息架构（IA）、题库列表形态和交互动效仍然沿用初版基础结构。这导致视觉感知仅仅是“换了一套黑白灰皮肤”，缺乏 Linear、Raycast、Supabase 等专业级生产力工具的质感与秩序。

本方案旨在针对全站展开**深度结构性重塑**，从以下五个核心维度全面推倒肤浅层，建立真正的极客生产力刷题体验：
1. **宏观布局（Macro Shell）**：引入 Linear 风格高密度工作台侧边栏 + `Cmd+K` 全局快捷指令入口，剔除粗暴的横排 Emoji 按钮。
2. **题库资产大厅（Assets Hub）**：将传统粗糙大卡片重构为高密度资产列表与健康度看板（等宽进度、FSRS 留存指示、薄弱项统计、快捷操作集）。
3. **沉浸式做题工作台（Practice Studio）**：题干排版字阶重塑，选项升级为具物理按压反馈的键盘导向条，官方解析与 AI 助教收敛为分层抽屉。
4. **图标与设计语言去肤浅化**：全仓清除生硬 Emoji，统一采用高精细度 SVG 线框矢量图标（Lucide 规范），严格遵循 4px 栅格与 1px 微发丝线系统。
5. **次级模块与弹窗收敛**：清除零散内联样式，统一采用 `CommandDialog` 规范深度重写。

## 详细实施计划 (Proposed Changes)

### 阶段 1：全局 Shell 与图标系统（消除 Emoji 玩具感）

#### 1.1 矢量图标系统建设
- 新增内联轻量 SVG 图标集（包含 `Terminal`, `BookOpen`, `Target`, `Cpu`, `Layers`, `Settings`, `Search`, `ArrowRight`, `Clock`, `Flame` 等），全面替换页面中的 Emoji（🎯、📊、📥、📐、📝、🤖、👤）。

#### 1.2 全局导航工作台 (`frontend/src/App.vue`)
- **[MODIFY] `frontend/src/App.vue`**
  - 构建左右分栏 Shell：左侧固定高质感深灰侧边栏（`linear-sidebar`），右侧为平滑过渡的内容工作区。
  - 集成快捷命令面板交互骨架（`Cmd/Ctrl + K`），支持随时在题库、错题、诊断、设置之间按键直达。
  - 维持登录鉴权、强制改密逻辑的无缝兼容。

---

### 阶段 2：题库大厅深度重构 (`HomeView.vue`)

#### 2.1 会话恢复终端 HUD
- 将原有的一大块黄色横幅改写为类终端风格的**「活跃作答会话 HUD」**：
  - 显示最近活跃题库、当前掌握度快照、做题进度百分比（如 `48% [████░░░░░░]`）；
  - 提供 `[Enter / 单击]` 立即恢复和 `[Esc]` 暂存，降低界面打扰感。

#### 2.2 高密度题库资产列表
- **重塑题库展示机制**：
  - 从“宽扁大卡片栅格”升级为“Linear / GitHub 资产工作台”：
    - **左侧列**：题库标题、题库类型标签（真题/模拟/专项）、更新时间戳。
    - **中间列**：掌握率迷你进度微图、FSRS 到期复习提醒胶囊（`3 题待复习`）、错题薄弱度标识。
    - **右侧列**：极简快捷操作条（`[快速练习]`、`[全真模考]`、`[管理]`）。
  - 建立空状态与极客风骨架屏。

#### 2.3 弹窗重写为 CommandDialog
- 清理 `HomeView.vue` 中所有未完成会话弹窗、蓝图弹窗的内联样式，统一采用 Linear 弹出卡片规范（暗黑磨砂玻璃背景、发丝边框、等宽键位关闭提示）。

---

### 阶段 3：做题与模考沉浸式工作台 (`PracticeViewV1.vue` & `ExamView.vue`)

#### 3.1 字阶体系与视觉锚点重塑
- **顶部极简状态栏**：
  - 压缩至 36px，左侧为返回与题库名，右侧为高精微缩进度 `08/40` 与倒计时，彻底告别臃肿占位。
- **题干区域**：
  - 顶部微字阶标签：`[单选题]`、`ID: #1042`、`难度: ★★★`（等宽字体 + 发丝线底衬）；
  - 题干正文采用 16px/1.65 行高排版，字间距经过精心调优，消除阅读视觉疲劳。

#### 3.2 选项交互组件（物理触感与键盘反馈）
- 选项卡条重塑：
  - 左侧：独立等宽按键方块（如 `1` / `A`），选中时呈现品牌翠绿微亮光；
  - 核心选项文本：采用更符合视觉动线的对齐与分段；
  - 动效注入：加入 `120ms cubic-bezier(0.2, 0, 1)` 微按压位移（`scale(0.99)`）与平滑发丝线描边变色，彻底消除生硬感。

#### 3.3 分层解析与认知评级板
- **解析面板**：
  - 区分「官方标准解析」、「AI 助教思维链」与「错因归因」三大独立标签卡，默认紧凑折叠，支持一键展开；
- **FSRS 认知评级板**：
  - 从四个朴素方块升级为**记忆调度仪表盘**：每个评级按键均标注预测间隔（如 `生疏 (+10m)`、`困难 (+1d)`、`良好 (+3d)`、`秒杀 (+7d)`），让极客用户直观感知算法力量。

---

### 阶段 4：次级流程与全局一致性 (`MistakesView.vue`, `LearningView.vue`)

- **错题斩杀大厅**：重构为清爽的错题治理看板，清晰呈现各错因分类的环形统计与待斩杀目标；
- **学习诊断大厅**：重构为现代数据仪表盘，高精度渲染记忆留存曲线与薄弱知识点雷达。
