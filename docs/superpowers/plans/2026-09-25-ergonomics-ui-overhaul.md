# 2026-09-25 EasyExam 人体工程学与交互工效学全面重构计划

## 1. 目标与范围
本批次重构旨在系统性修复 EasyExam 全站（重点在 `PracticeViewV1.vue` 练习刷题、`ExamView.vue` 模拟考试、`HomeView.vue` 题库首页及 `style.css` 全局样式）中存在的人机工程学与费茨法则严重硬伤。

## 2. 核心工效学整改要点
1. **解决“提交在极左，下一题在极右”的左右横跳问题**：
   - 统一至常驻操作底栏或同侧同槽位（Fixed Ergonomic Action Bar），判分前为“提交答案”，判分后在相同位置直接变更为“下一题”，位移归零。
2. **补充练习模式“上一题”可逆导航**：
   - 在底部栏左侧提供“上一题”按钮，解决手滑错跳无法回看的问题。
3. **全键盘盲操支持**：
   - 全局快捷键：`A/B/C/D` 或 `1/2/3/4` 选项选中；`Enter` 提交；`Space` / `→` 下一题；`←` 上一题；`F` 标记薄弱；`1-4`（判分后）评级。
   - 输入框激活（textarea/input）时自动挂起单字母快捷键。
4. **移动端模考防误触与首屏净化**：
   - 移除 `order: -1` 答题卡置顶，改为底部抽屉唤起或顺序列出；
   - 移除移动端通栏“交卷”大按钮，恢复为受保护的次级操作；
   - 模考答题卡增设图例说明（已答/待复查/未答）；
   - 交卷拦截弹窗支持点击“直达未答题”。
5. **视线与触感体验优化**：
   - 触控目标达标（最小高度 42-44px），增加 active 按压反馈；
   - 题目卡片与判分结果平滑过渡，消除丢焦抖动；
   - 题库首页“开始刷题”凸显 Primary 高亮，解决并列次要按钮的主次不清。

## 3. 验收标准 (DoD)
- `npm --prefix frontend run test` 全绿，增加快捷键与答题卡导航测试；
- `npm --prefix frontend run build` 产物正常构建无警告；
- 键盘操作在浏览器中实现全程无需鼠标操作；
- 移动端 375px/390px 下题干位于首屏核心视野，无误触交卷风险。
