# EasyExam 台账全量缺陷与能力缺口修复计划 (EE-001 ~ EE-021)

本计划旨在依据 `docs/REQUIREMENTS_TRACEABILITY.md` 中的 EE-001 至 EE-021，逐项修复已确认的业务缺陷、数据隔离与可靠性风险，并补齐已确认的 SPEC 功能缺口。

---

## 阶段划分与批次

### 批次 1：P1 级核心业务 Bug 与数据可靠性修复
- **EE-016**: 修复学习推荐薄弱题筛选 Bug (`include_weak=False` 必须彻底排除手动标记薄弱题与错题薄弱题，使用结构化字段)
- **EE-017**: 修复跨题库推荐启动丢题 Bug（支持按题库聚合启动或多题库会话明确透传，不静默丢题）
- **EE-002**: 修复模考错题策略失效 Bug（在考试档案/蓝图和会话中持久化 `record_mistakes` 开关，提交/交卷根据开关控制错题记录写入）
- **EE-013**: 修复离线题目编辑队列按用户隔离与防丢失重放（使用 `easyexam_offline_edits_{userId}`，逐项成功确认后删除，登出安全隔离）
- **EE-019**: 补齐未完成模考/练习会话恢复入口（服务端提供用户活跃未完成会话接口，前端首页提供“恢复未完成模考/练习”入口）
- **EE-018**: 接通跨设备事件同步前端链路（登录后启动游标事件拉取与变更回放，保持状态一致）

### 批次 2：模考蓝图与组卷引擎 (EE-001, EE-010)
- **EE-010**: 补齐考试档案与蓝图管理 API（列表、读取、创建、更新），前端提供可视化蓝图配置面板
- **EE-001**: 模考组卷引擎真正接入蓝图规则（按题型配比、章节权重、难度约束动态筛选组合题目，不足时按 SPEC 降级）

### 批次 3：AI 助教、联网搜索与变式题草稿 (EE-004, EE-003, EE-005)
- **EE-004**: 生产 AI 助教默认注入可配置的联网搜索适配器（`OpenWebSearchAdapter`），并完善优雅降级
- **EE-003**: 个人资料与题库解析检索接入 AI Prompt（检索当前题目相关的个人笔记/摘要与知识点资料，注入系统提示词）
- **EE-005**: 实现 AI 变式题草稿闭环（API 支持生成变式题草稿、草稿暂存表、前端展示草稿、用户确认后生成正式题目版本入库）

### 批次 4：题目运维、章节知识点、共享与管理 (EE-007, EE-008, EE-011, EE-012, EE-020)
- **EE-007**: 题目版本正式关联章节与知识点实体（补齐题目与 chapters / knowledge_tags 的稳定关联与读写维护）
- **EE-008**: 题库导出接入 V1 路由（支持 JSON / CSV / TXT / Excel 导出并校验成员权限）
- **EE-011**: 完善单题手动管理界面（前端支持完整题目新增、完整字段编辑包括题型/选项/答案/解析/难度/标签，保留版本历史）
- **EE-012**: 补齐个人资料管理界面（支持查看个人笔记/上传文件提取内容、按知识点/题目筛选与删除）
- **EE-020**: 补齐共享题库成员管理与题目跨库复制前端流程（查看成员列表、添加成员角色、题库题目复制到其他题库）

### 批次 5：测试维护、版本标识与决策裁定准备 (EE-014, EE-015, EE-006, EE-009, EE-021)
- **EE-014**: 修复本地浏览器端到端测试 `frontend/tests/browser_e2e.test.js` 中的过时 DOM 定位器与时序，确保全量 E2E 真实通过
- **EE-015**: 在后端健康检查接口 `/api/v1/health` 中注入构建标识 / git commit SHA，实现版本可追溯映射
- **EE-006 / EE-009 / EE-021**: 梳理 SPEC 决策依赖项，对重判范围、密钥持久化安全边界及 PDF 冲突提出精确决策方案与可选方案，待用户裁定
