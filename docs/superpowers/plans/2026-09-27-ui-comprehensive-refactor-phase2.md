# 方案2 全系统界面与交互深度大扫除实施计划

> 日期: 2026-09-27  
> 目标: 彻底治理真正的刷题界面、移动端首页物理预算、导入页断层、模考成绩单时序错乱及深层弹窗交互粗糙问题，达成桌面与移动端全场景高品质体验。

## 一、改动清单与任务分解

### Task 1: 真正刷题界面 (`PracticeViewV1.vue`) 现代化彻底重构
1. **顶栏压平为标准 48px 单行 App Bar**：
   - 左侧：`[← 返回]` + 标题 + `[题型]` + `[1/2 📑 答题卡]` 严格单行水平对齐，间距 8px~12px；
   - 右侧：5 个操作按钮横向水平展开（`交卷` 高对比 Primary 蓝，其余为干净线框次级按钮）；
   - 彻底清除纵向 3 层断行与 5 键竖直堆叠，移除超高无用空白。
2. **作答区域居中视野与弹性展开**：
   - 作答前题目卡片置于居中舒适阅读宽度（840px~920px），消除右侧空洞的虚线“✍️ 专注作答中”占位卡片；
   - 作答后平滑向右展开解析面板与 FSRS 四档评级条。
3. **消除原生 `window.alert` / `window.confirm`，引入现代化刷题完成报告面板**：
   - 替换浏览器原生弹窗，引入原生 Vue 结算模态卡片（得分、正确率、耗时、答题统计、返回题库 / 再练一次）。
4. **桌面端答题卡弹窗居中**：
   - 桌面端视口垂直居中，移动端保持底部抽屉。

### Task 2: 首页移动端顶栏 5 层塔式结构瘦身 (`HomeView.vue`)
1. **压缩移动端顶栏高度（≤60px）**：
   - 第一行：品牌标题 + 用户名胶囊 + `[+ 题库]`；
   - 第二行：紧凑的横向功能胶囊（学习诊断、错题斩杀、导入）；
   - 工具按钮收进折叠菜单，把首屏黄金视野完全留给题库卡片。
2. **单题手动录入弹窗 (`add-question-dialog`)**：
   - 标准答案由自由单行文本框改为选项左侧单选点选 Radio；
   - 选项删除按钮由单字 `删` 优化为图标；
   - 弹窗增加 `max-height: 85vh; overflow-y: auto;` 防截断。
3. **模考设置弹窗 (`exam-setup-dialog`)**：
   - 修复 Checkbox 孤立浮在文字上方的换行问题，水平居中对齐。

### Task 3: 全真模考界面 (`ExamView.vue`) 修复
1. **题型英文枚举映射**：将题干右上角的 `SINGLE` 映射为中文胶囊（`单选题` / `多选题` / `判断题`）。
2. **成绩单报告页顶栏时序错乱修复**：
   - 交卷后进入报告状态时，顶栏卸载计时器与交卷按钮，切换为 `[← 返回题库] 模拟考试成绩单`；
   - 报告单卡片布局居中，增加对错题展开复盘列表，消除 75% 惨白空洞。

### Task 4: 题目导入界面 (`ImportView.vue`) 断层修复
1. 修复顶栏 `[返回]` 与 `导入题目` 标题被 `space-between` 撕裂 1100px 的严重断层，将标题收回到返回按钮右侧。
2. 现代化美化拖拽上传卡片。

### Task 5: 错题本与斩杀归档 (`MistakesView.vue`) 空状态优化
1. 错题本 Tab 与斩杀归档 Tab 增加居中优雅的空状态（矢量图标 + 引导文案 + 快捷刷题入口）。

### Task 6: 学习诊断页 (`LearningView.vue`) 数据兜底
1. 近期指标卡片无数据时规范显示 `0 次` / `0%` / `--`，消除裸冒号残缺。
