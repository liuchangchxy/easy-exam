# 共享题库权限与交卷终态修复

**目标：** 按 SPEC 的共享题库角色规则及“已交卷会话拒绝后续作答”要求，修复角色检查缺口和交卷后的迟到写入。

**范围：**
1. 章节、知识点标签创建仅允许 ADMIN/EDITOR。
2. 作答写入在数据库事务内重新核对会话仍属于用户且未完成，消除检查与写入之间的竞态。
3. 草稿同步和标记切换拒绝已完成会话。
4. 增加 API 回归测试；在需求追踪台账记录本次结论及尚未修复的审查项。

**不在本批次修复：** 模考答案经其他题目接口暴露、导入难度归一化、学习趋势统计口径。它们作为独立审查缺陷登记，避免扩大本批次。
