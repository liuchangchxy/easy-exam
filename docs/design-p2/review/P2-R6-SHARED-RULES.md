# P2 第六轮 · 共享规则与文件归属

本文件是本轮所有并行工作的唯一契约。先读完再动手；与本文冲突的做法一律以本文为准。

## 0. 不可退让

- 只改 `docs/design-p2/`。不碰生产代码、P1 规格源文件、测试、Git 门禁。
- 保留 Direction D 视觉方向、现有令牌、现有组件语言与已正确的交互。不推倒重做。
- 不新增产品功能；只把 brief 要求的价值、效率、层级、排版、文案做到位。
- 所有页面必须在产品模式（不带 `?spec=1`）下成立；`data-spec` 内容不算产品 UI。
- 新增中文文案先按普通中文写，由 E 域统一补 `assets/i18n.js`；不要在页面里硬编码英文。

## 1. 术语（全产品统一）

| 概念 | 用词 | 不用 |
|---|---|---|
| 复习入口 | 待复习 / 错题 / 薄弱 / 斩杀 | 到期复习、错题本、弱项、已斩杀 |
| 练习顺序 | 顺序练习 / 随机练习 | 顺序模式、乱序 |
| 模考类型 | 快速模考 / 蓝图模考 | 基础模式、普通模考 |
| 开始动作 | 开始练习 / 开始模考 | 开始学习（除非指整个学习任务） |
| 题目处置 | 标记薄弱 / 取消标记 / 斩杀 | 收藏、加入错题、不再练（对话标题除外） |
| 正确率 | 正确率 | 已答客观题正确率（主指标位） |
| 用时 | 总用时 | 墙钟时长、耗时 |
| 得分 | 得分 / 满分（同一行） | 客观题得分、卷面总分（主指标位） |

「斩杀」只在确认对话框里解释后果；列表与按钮直接用「斩杀」。

## 2. 视觉基线

- 只用现有令牌（`--ink-*`、`--surface*`、`--line`、`--brand*`、`--ok/warn/bad*`、`--sp-*`、`--text-*`、`--r-*`）。不新增颜色。
- 字号阶梯沿用现有 8 级；正文 ≥14.5px，阅读正文 16.5px。
- 中文标题行高 ≥1.3；中文正文 1.7；英文标题可用 1.15–1.25。
- 数字（得分、题量、百分比、时间）用 `font-variant-numeric: tabular-nums`；不要给整段中文套等宽字体。
- 按钮高度统一：sm 28 / 默认 32 / hero 40。同一操作区内的按钮必须同高、同基线。
- 间距只用 4 的倍数；区块间距优先 16/24/32。
- 图表只用现有语义色：正确 `--ok`、错误 `--bad`、部分 `--warn`、未答 `--line`、未判分 `--ink-3`。颜色必须配文字或图形，不单靠颜色。

## 3. 开始面板契约（所有入口共用）

- 一个对话框解决：来源（题库 / 范围）→ 顺序（顺序 / 随机）→ 题量（10 / 20 / 50 / 自定义）。
- 直接显示「可练 N 题」；题量输入上限 = 可练题量；非法值就地说明，不进入下一步。
- 常用题量是一排可点的分段/胶囊，不是下拉；自定义是同一行的数字输入。
- 次要筛选（题型 / 章节）默认收起，用「更多筛选」展开；已选条件以 chip 显示并可单个移除。
- 会话冲突只在真的存在同模式会话时出现在面板内，给出「继续上次 / 结束并新建」，不额外弹一层。
- 主按钮固定为「开始练习」/「开始模考」；没有「调整参数」这一步。
- 开始后实际试卷题量必须等于面板显示题量；不足时在面板里先说明，不允许进去才发现。

## 4. 答题器底栏契约

- 底栏三段：左（上一题，次级）、中（进度 + 答题卡入口）、右（主操作，固定宽度，不因文案变化移动）。
- 主操作状态机：未提交 =「提交答案」；已提交且非末题 =「下一题」；已提交且末题 =「完成练习」。
- 「跳过」是次级文字按钮，放在左侧，不与主操作抢位置。
- 主操作按钮宽度按最长文案预留，三态切换不改变布局。
- 快捷键提示放在对应控件附近（选项区、底栏、评级区），不集中堆在帮助浮层里。电脑端默认显示、触屏默认隐藏；设置里可开关。
- 普通练习不显示 FSRS 手动评级与调度说明；复习 / 错题重做才显示。

## 5. 成绩报告契约

三级层级，从上到下：

1. **核心成绩**：`得分 / 满分` 同一行大数字；得分率、正确率、总用时三个次级指标。
2. **学习分析**：答题结果分布（横向堆叠条 + 图例）、按题型表现（紧凑条形）、薄弱章节（Top 3–5 条形）。
3. **详细信息**：逐题明细（可筛选、批量展开）、完整统计表、判分版本、交卷信息，默认折叠或下沉。

- 计算口径收进「怎么算的」按需展开，不写成主标题。
- 正确 / 错误 / 部分正确 / 未答 / 未判分：颜色 + 图标/形状 + 文字三重区分。
- 答题卡格子固定 36×36（窄屏 32×32），列数自适应，不随容器放大。
- 点题号 → 定位并展开对应解析。
- 即时报告与历史报告使用同一结构、同一组件、同一交互；历史报告只读、不回算。
- 历史报告缺逐题明细时明说缺什么，不用演示数据填充。

## 6. 文案

- 短句、自然中文；一句话能说清的不写两段。
- 删除：规格口吻、内部实现术语（落库、快照、幂等、墙钟）、重复解释、无决策价值的说明。
- 结果已由界面表达时，不再弹 toast。
- 错误提示写「原因 + 怎么办」，不只写「失败」。
- 新增/修改的每条中文文案记进交付报告，供 E 域补英文。
