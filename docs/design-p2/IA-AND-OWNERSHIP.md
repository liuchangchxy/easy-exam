# EasyExam P2 · 信息架构与 FN 设计归属矩阵（设计权威文件）

本文件是 P2 的**设计裁定**，与 `CONTRACT.md`（视觉与控件合同）共同构成屏幕构建依据。
产品语义的唯一权威是 `docs/product-spec/`（`f2e25ed`）的**第一层「产品最终应该怎样工作」**；
本文件只决定「它落在哪个页面、用什么载体、有哪些状态」，不重新裁定产品语义。

## 一、一级导航：5+1（FN-602 / 00 册 §4.2）

| 导航项 | 路由 | 职责（单一，不重叠） |
|---|---|---|
| 今天 | `/` | 我今天该做什么：计划、开始学习、继续会话、提分推荐 |
| 题库 | `/banks` | 题目资产的拥有与管理：题库列表、工作区、导入 |
| 复习 | `/review` | 已产生的学习债务：到期、错题、薄弱、斩杀 |
| 模考 | `/exams` | 正式考试：档案、蓝图、组卷、报告 |
| 资料 | `/notes` | 学习材料：笔记、总结、知识手册、上传文件、AI 解释 |
| 设置 | `/settings` | 低频管理：账户、偏好、外观、AI 配置、关于（侧栏底部） |

**职责切分原则**：一级项按「用户意图」分，不按「后端实体」分。
- 「今天」与「复习」的分界：今天回答「做什么」，复习回答「欠什么」。到期集合在复习页呈现，今天页只呈现**数量与入口**，不重复列表。
- 「题库」与「复习」的分界：题库是资产侧（增删改查、导入、协作），复习是学习侧（做题、斩杀、归档不在此）。
- 「模考」与「复习」的分界：模考是正式考试的全过程，复习是零散刷题。
- 「资料」与「题库」的分界：资料是游离材料，可关联题目；题目本体归题库。

## 三、载体选择规则（page / dialog / drawer / menu）

| 场景 | 载体 | 理由 |
|---|---|---|
| 创建或编辑一个短实体（题库、资料、章节、标签、成员邀请） | **dialog** | 有明确提交边界，不依赖主内容上下文 |
| 查看或编辑主内容某一侧的内容（题目编辑、版本历史、字段映射帮助、成员角色变更） | **drawer** | 需要与主内容对照，宽度可变 |
| 对一行或多行的上下文操作（题目行「更多」、批量条操作） | **menu** | 操作集短，不打断浏览 |
| 同一实体下并列的子视图（工作区六页签、资料四分部） | **tabs** | 语义平级，URL 记录当前页签 |
| 改变集合定义或过滤条件（我的/共享给我、题库分类、资料类型） | **segmented + URL** | 是查询条件不是视图 |
| 多步骤且每步需要专注的长任务（导入向导） | **page + steps** | 需要面包屑、可中断续做 |
| 沉浸式单任务（普通练习、考试会话） | **全屏 runner** | 排除一切导航干扰 |
| 破坏性或不可逆确认（删除、转移所有权、交卷、退出放弃） | **danger dialog** | 必须显式二次确认 |
| 短暂成功反馈 | **toast** | 不阻断 |
| 持久结论 / 失败原因 / 批量结果 | **notice** | 需要被读到 |
| 移动端的上下文详情与表单 | **drawer（底部弹出变体）** | 单手可达，不失去页面背景 |

**禁止**：把本应是 dialog 的短表单做成一整个 page；把需要对照主内容的编辑做成全屏 dialog；用 tabs 表达过滤条件；用 menu 承载两个以上层级。

## 四、状态矩阵（每个屏幕必须显式设计）

| 状态 | 通用表达 | 特殊说明 |
|---|---|---|
| 空 | `.empty`（原因 + 下一步 CTA） | 必须说明**为什么**空，不是「暂无数据」 |
| 加载 | `.skeleton` | 与真实内容同构 |
| 错误 | `.notice.bad` + 重试 | 错误原因必须可读 |
| 禁用 | 禁用控件 + `.hint` 说明原因 | **只适用于「与当前用户相关」的控件**；完全无关的管理入口不渲染（CR-12） |
| 无权限 | `.notice.warn` 或整页 `.empty`（403 语义） | 越权两种变体都设计 |
| 冲突 | `.notice.warn` + 「查看我的版本 / 使用对方版本」 | 草稿冲突 FN-216/423、题目冲突 FN-115、并发编辑 FN-424 |
| 未配置 | `.notice.info` + 去配置的链接 | AI 未配置 FN-510/518、无蓝图 FN-311、注册关闭 FN-405 |
| 离线 | 持久标识 + 队列计数 + 重试 | 离线作答队列 FN-217、同步态 FN-617 |

**禁用 vs 不渲染（CR-12 两向规则，本轮恢复 P1 完整语义）**：判据是「这个入口说的事，对这个用户有意义吗」。
有意义但不能做 → **禁用并解释**（置灰 + `.hint` 可读原因）；没意义 → **不出现**。
只对「库与实例的管理权」判定相关性——普通成员看不到题库设置/归档题库/删除空库，普通用户看不到实例管理入口；
内容操作（编辑题目、批量维护、导入）与成员名单对所有成员都有意义，一律禁用并解释。
实现分工：`store.js` 的 `can(action)` 答「能不能做」，`relevant(action)` 答「跟这个用户有没有关系」。
