02 / EasyExam UI/UX 设计规范

控件库

每一种控件只有一种实现。本章定义全部控件的形态、全部状态与行为边界；新页面不允许创造新控件形态，也不允许用十六进制或内联样式绕过令牌。

09对话框

全站只有一种对话框：原生 `<dialog>` + `.dlg-*` 三槽结构；尺寸差异只用 `wide` / `narrow`，破坏性确认只用 `danger`。打开：`eeDialog.open('id', this)`；关闭：`data-dlg-close`。

标准 .dlg
.dlg.wide · 多列表单
.dlg.danger · 不可逆确认

初始焦点：打开时聚焦 `[data-autofocus]` 或首个可聚焦元素，不落在关闭钮上。

退出：Escape 与点击遮罩都等于「取消」；关闭后焦点回到触发按钮。

未保存保护：取消类关闭（Escape / 遮罩 / 无动作的关闭钮）时，若用户改过表单且没有改回打开时的值，先弹「放弃未保存的更改？」确认——继续编辑回到原对话框（焦点与已填内容都在），放弃更改恢复打开时的值并关闭。程序预填不算未保存；带动作的按钮（`onclick` / `data-dlg-commit`）是提交，不过问。需要整体保护的用 `data-dlg-guard`，明确不保护的用 `data-dlg-noguard`，非表单内容可用 `eeDialog.markDirty(dlg)` 显式标记。

按钮次序：取消（quiet）· 破坏（danger-solid）· 确认（primary）；从左到右按此序，实心钮只有一个。

12表格

全站只有一种表格 `.dtable`：桌面为表格，≤640px 同一 DOM 自动转卡片（列名移入 `::before`）；每个 `` 必须带 `data-label`。

12.1 选择模型

需要批量操作的表格在第一列放复选框（`.col-check`）。选择集是按题目 ID 的显式集合（`tr[data-row-id]`），不是 DOM 属性——筛选变化不静默丢掉已选条目。

全选 = 当前筛选结果，不是整个题库：表头复选框只切换当前可见行，被筛掉的行不受影响。

半选态：可见行选中一部分时，表头复选框为 `indeterminate`。

跨筛选保留：行离开当前筛选后仍保持选中；计数显示总已选，并额外说明「含 N 条不在当前筛选内」，避免用户以为批量动作只作用于眼前几行。

清除选择：一个按钮清空整个集合（含不可见行），不需要用户逐行取消。

锁定行跳过：模考中 / 无权限编辑的行复选框禁用，全选与批量动作一律跳过它们，并说明原因。

批量动作：未选中任何行时禁用（「清除选择」保持可点），不出现空批量请求。
