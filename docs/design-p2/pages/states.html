03 / EasyExam UI/UX 设计规范

状态与外壳

八种状态是全产品统一契约：任何屏幕不得只设计「正常那一档」。命令面板、快捷键、同步态、URL 状态契约与跨端断点同属全局外壳，由本页定义，各屏直接引用。

查看控件库

01八态矩阵

每个屏幕都必须显式设计下面八种状态，并用同一屏内的不同面板并列呈现。空态必须说明为什么空并给出下一步动作；禁用必须给出可读原因，但只适用于与当前用户相关的控件；完全无关的管理入口不出现；未配置与离线不是错误，是正常的产品状态，要有自己的表达。

八态契约：状态、触发条件、统一表达、禁止事项
状态 触发条件 统一表达 禁止
空 集合本身为空（不是加载失败） .empty：空标 + 标题 + 为什么空 + 下一步 CTA 只写「暂无数据」；给一个死按钮
加载 首次进入、切换筛选、翻页 .skeleton + .sk-line／.sk-block，与真实内容同构 整页转圈；骨架与真实结构不一致导致跳动

02命令面板（FN-605）

命令面板是全产品唯一的「跨页直达」通道，用来缩短高频路径，不是又一个导航。它只做三件事：跳到某个页面、对当前对象执行一个动作、切换一个全局设置。与当前用户相关但无权限的命令置灰并说明原因；与当前用户完全无关的管理入口不出现。

打开方式：⌘K / Ctrl+K，或点这里
移动端：底部抽屉变体，同一份命令数据

命令的分组与权重

命令面板收录规则：高频学习动作优先，管理动作收在「转到」分组
分组示例规则
今天 继续上次练习 / 开始今日复习 / 查看今日计划 永远排在列表最上方，带当前上下文（如「还有 5 题到期」）
转到 题库工作区 / 学习档案 / 模考中心 / 资料库 / 设置 页面级跳转，无权限的目标不出现（用户根本看不到那个对象）
对当前对象执行 归档本题 / 标为薄弱 / 加入斩杀 / 导出题库 只在对应页面出现；相关但无写权限时置灰 + 原因，完全无关的管理命令不出现
设置 切换暗色 / 切换配色 / 切换语言 / 切换密度 即时生效，执行后 toast 确认

空结果也是有意义的：搜不到时说明「没有匹配的页面或命令」，并列出三个最可能的命令，不要让用户面对一个空列表。

03全局快捷键（FN-612）

快捷键只覆盖两类：跨页导航与 runner 内的作答操作。每个快捷键在命令面板里都能用文字搜到，不强迫记忆。

快捷键不得拦截正常输入：焦点在输入框 / 文本域 / 可编辑元素里时，字符类快捷键一律不触发（输入法组合输入同样不触发）；带 Ctrl/⌘ 的组合键让给系统与浏览器。快捷键按题型动态适配——单选题按 A–E 选对应选项，多选题同键切换选中，判断题按 T/F，填空题聚焦输入框时不拦字符键，主观题不启用字符类快捷键。不为了增加高级感堆砌低价值快捷键：帮不上高频路径的一律不加。

04同步态 / 在线态 / 多标签页（FN-617）

同步状态用一个常驻但不抢注意力的标识表达。它只在「需要用户知道」时升级为通知：离线且队列非空、同步失败、另一个标签页正在改同一对象。

顶栏常驻标识（四态）
已同步 同步中 离线 · 队列 3 同步失败
多标签页冲突

另一个标签页正在改这道题

这个页面已切成只读，避免两边同时写。回到那个标签页保存后，这里会自动恢复。

宽限期（CR-31）——不是失败

作答窗口已结束，宽限 60 秒

你的答卷已在本地封存，正在等服务端收卷。这 60 秒里网络恢复就会自动补交；超时则由服务端按已封存内容收卷。不会判定你缺考。

「作答窗口结束」不是会话终止。宽限期内界面必须是正常状态（info 级），不能变红、不能报错。只有服务端明确收卷失败才进入错误态，并给出重交入口。

05URL 状态契约与可深链（FN-614）

能被分享、被刷新、被记住的状态必须进 URL。同一语义只允许一种 URL 写法，别名与重复参数一律禁止——否则 P3 会出现两个入口指向同一屏却行为不同。

进 URL 的状态与不进 URL 的状态
状态进 URL写法说明
当前页签进 /review?view=due 四个值：due / mistakes / weak / killed
分段（集合定义）进 /banks?scope=shared scope=mine / shared
筛选与检索词进 /banks/12/questions?q=缓存&chapter=3 刷新后保持，可分享给同事
分页进 ?page=3 配合筛选词一起变
主题 / 配色 / 密度进 ?theme=dark&palette=gruvbox 同时写入本地偏好，URL 参数优先
语言进 ?lang=en-US 同主题
浮层开闭不进 — 对话框/抽屉/菜单是瞬时状态，进 URL 会造成返回键歧义
runner 内的题目位置进 /practice/s/88?n=7 断点恢复与跨设备续考靠它
登录回跳目标进 /login?next=/review/diagnosis 目标不可达时回落今天，不报错

非法参数一律回落，不白屏：/review?view=all（已废弃的别名）与 /review?view= nonsense 都回落到 view=due，并在首屏用一次 toast 说明「已回到待复习」。

06跨端断点与软键盘 / 安全区（FN-615）

三档共享同一套 DOM 与同一套语义，只改布局与交互方式，不做机械缩放。判断标准是「这只手现在能做什么」，不是「这块屏有多宽」。

四档断点：1440 / 1024 / 768 / 375
档位 导航 布局 交互方式
>1024 桌面 完整侧栏 236px + 顶栏 统一纸面居中 1120px（全产品同一张纸）；列表双栏 鼠标 + 快捷键；hover 有反馈；右键菜单不用，一律用「更多」按钮
769–1024 平板 侧栏收成 64px 图标轨 + 顶栏 纸面通栏，双栏收成单栏 + 右栏下移 触屏；hover 失效的状态必须有 active/selected 兜底；批量条常驻底部
641–768 小平板 侧栏隐藏，底部导航 6 项 单列；表格转卡片（td[data-label]） 触屏 + 拇指可达区优先；底部固定操作区
≤640 手机 侧栏隐藏，底部导航 6 项 + 移动顶栏 单列；长文限宽 .measure 68ch 单手拇指；触摸目标 ≥44px；表单避免被软键盘遮

断点取 768，这是唯一判据。70 册 §6 的跨端行为表把 641–1024 整段归为平板（侧栏图标轨、底部导航不显示），而 CR-28 规定「底部导航与侧栏不得并存」。两处对 641–768 给出相反答案，本设计以侧栏是否可见为唯一判据：>768 侧栏可见（>1024 完整 / 769–768 图标轨），≤768 侧栏隐藏并由底部导航接管。实现见 ee.css（max-width:768 隐藏侧栏、min-width:769 隐藏底栏），文档以它为准。

移动端专项（不为桌面视觉牺牲移动可用性）

单手操作与触摸目标

主要操作落在屏幕下半部的拇指弧内：底部导航、底部固定操作条、抽屉从底部弹出。次级操作（返回、更多）在顶部，但都不应是完成任务的唯一路径。

任何可点元素不小于 44×44（.od-touch）；列表行的整行可点，不只点标题。

作答卡与答题卡

手机端答题卡是从底部拉出的抽屉，不是右侧常驻栏——常驻栏会把题干挤到一行三个字。格子在抽屉里保持 5 列，已答/当前/待复查三种态用形状 + 颜色双编码，不只靠颜色。

表单与软键盘

软键盘弹出时，页面滚动到当前输入框，提交按钮跟随键盘上浮。占位高度由 assets/spec-boot.js 用 visualViewport 实时写进 --kb-inset（键盘收起归零，地址栏收缩一类的小抖动不算键盘），底部操作条的 bottom 直接吃这个变量；需要收起的次要区域加 .kb-hide，需要收缩的加 .kb-shrink。不在软键盘上方再放一层浮层。

对话框 / 抽屉 / 长文

手机端对话框改为底部抽屉式，标题与关闭在顶部，主操作在底部；长文（解析、资料）限宽 68ch 并保留纸面底色，不用纯白背景。

固定操作区 vs 页面滚动

只有「当前这一步的主操作」固定在底部（提交答案、交卷、保存），且固定区不超过一个按钮组。页面内容在固定区下方滚动，不被遮挡（.has-bottomnav 已处理）。

安全区

底部导航与固定操作条用 env(safe-area-inset-bottom) 留出主屏幕指示条的空间；顶部用 viewport-fit=cover 处理刘海。横屏时底部导航保持可见，不因键盘高度抖动。

07全屏 runner 外壳与退出确认（FN-616）

练习与考试是全产品唯一进入全屏的场景。全屏的意义是排除导航干扰，所以 runner 内不出现一级导航，只保留退出、进度与交卷。退出必须确认，并且要说清楚「退出了会怎样」。

练习 · 退出确认

「退出后这组的作答会存成草稿，你可以从今天页继续。已提交的评级不会撤回。」两个按钮：继续练习（主）/ 退出并存草稿（quiet）。

考试 · 退出确认

danger 对话框。「现在退出会暂存草稿，你可以在宽限期内从同一台或另一台设备续考。超过宽限期服务端将按已暂存内容收卷。」确认按钮写「退出并暂存」，不写「确定」。

runner 内不允许出现的东西

一级导航、面包屑跳转、设置入口、与当前题无关的推荐。它们全部收进退出后的正常外壳。
