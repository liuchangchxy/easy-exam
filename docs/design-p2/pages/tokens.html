01

配色

Color & Palettes

四个配色家族 × 明暗两套，共八种组合。语义色只有一套承载体量的 accent（brand）与三组状态色（ok / warn / bad）；所有色块由 var(--paper) 等令牌着色，十六进制仅作为文字标注。切换家族与明暗会改写 html 元素上的 data-theme / data-theme-palette，页面 chrome 与下方「当前生效」条随之实时变化。

家族卡片常驻全部八种组合，因此色板不随页面切换而改变（每张卡片把 data-theme-palette 写在自己的行上，让 var(--paper) 在该行上下文里解析为对应家族的值）；当前生效的那一套会以品牌色描边标出，对应的明暗行高亮。对比度由令牌本身保证，明暗两套均满足正文 ≥4.5:1、大字号与图标 ≥3:1。

02

字号

Type Scale

从 --text-xs 到 --text-5xl 的完整十档，是全站唯一字号来源，取代原先 20 余处散落的字面量。每一档都配有行高令牌 --text-*-lh；标题与题干档用衬线（--font-serif），辅助与正文档用无衬线（--font-sans）。

档位px / 行高示例用途
--text-xs 12 / 1.40 辅助说明 · 图例与脚注 辅助、图例
--text-sm 12.5 / 1.45 元信息 · 2026-11-13 第 46 周 元信息、表格次要列
--text-base 13.5 / 1.65 正文：桌面端默认字号，承载界面里绝大多数文案、列表与表单。 正文（桌面）
--text-md 15.5 / 1.70 阅读性正文：题干辅助与长段落的舒适阅读区。 阅读、题干辅助
--text-lg 17 / 1.50 小节标题 小节
--text-xl 19 / 1.45 题干：关于系统分析的说法，正确的是？ 题干、抽屉标题
--text-2xl 22 / 1.35 区块标题 区块
--text-3xl 26 / 1.25 页面标题 页面
--text-4xl 32 / 1.20 今天，从一套真题开始 首页大标题
--text-5xl 38 / 1.15 把错题变成下一次的把握 首页大标题（宽屏）

移动端 <=768px 时页面标题自动降到 --text-2xl（ee.css §11），标题不再有第二套移动字号。

03

间距

Spacing

--sp-1 至 --sp-10 十档，全部落在 4px 基阶上：每档 = 4 × n（n = 1…10），覆盖 4–72px。色块宽度即令牌真实宽度，所有间距可对齐到同一网格，不再出现随手写的 13px、17px。

信息密度：间距有两档。宽松（默认，不写属性）用上表原值；紧凑把 html 置为 data-density="compact"，间距整体收一档（--sp-2 8→6px、--sp-6 24→18px…），同时压紧列表行与表格单元格的上下内距。切到「紧凑」后本页的间距表、列表行与表格会实时变密——密度不是新令牌集，只是同一组令牌的另一个取值，屏幕不得自己定义第三档。

--sp-14px分段与菜单内距、chip 间距
--sp-28px按钮间距、字段间距、标题与元信息间距
--sp-312px列表行内距、表单元格距、图标与文字间距
--sp-416px面板头/脚内距、分区间距
--sp-520px面板主体内距、区块间距
--sp-624px内容区左右留白、空态内距
--sp-732px分区间距、页头下间距
--sp-840px空态大留白、骨架区间距
--sp-956px页面级留白
--sp-1072px首页与空态级大留白

图标尺寸不走间距阶梯：--od-icon-size 按上下文取 13–28px（按钮内 13/14、正文 16、导航 17/20、空态 28）。

04

圆角与阴影

Radius & Shadow

圆角四级，上限 4px——合同禁止大圆角、胶囊与「气泡感」；--r-xs 与 --r-sm 同为 2px（v3 收敛时保留的历史档位，实际取值一致）。阴影只有两级：微浮层用一级，对话框/抽屉/菜单/toast 用二级。

--r-xs 2px · 标签、键帽、作答卡
--r-sm 2px · 按钮、输入框、菜单项
--r-md 3px · 面板、表格、菜单
--r-lg 4px · 对话框、抽屉（全站最大圆角）
--shadow-1 0 1px 2px rgba(25,27,24,.05) 微浮层：分段选中态等贴面元素
--shadow-2 0 24px 64px -20px rgba(25,27,24,.3) 重浮层：对话框、抽屉、菜单、toast

深色下两级阴影同步换为黑色系（rgba(0,0,0,.3) / .6），由 [data-theme="dark"] 覆盖，无需在组件里分支。

05

布局

Layout Scales

六个布局尺度令牌决定外壳与内容区的几何。比例条以统一纸面 --d-max（1120px）为满尺，条长即真实占比。

--sidebar-w 236px 侧栏宽（>1024 完整形态）；≤1024 收为 --sidebar-w-icon 64px 图标轨
--topbar-h 56px 桌面顶栏高（移动顶栏 --mobile-top-h 52px）
--bottomnav-h 64px 移动底部导航高（仅 ≤768 显示，六项）
--reading-w 744px 阅读栏宽：题干与长文段的舒适度量
--page-w 1120px 页面内容最大宽（= --d-max），常规屏幕封顶值
--d-max 1120px 唯一纸面宽度：全产品普通页面共用同一张纸，功能差异在纸面内部用排版解决

正文行宽另有 --measure: 68ch 作为度量上限；左右轨宽 --rail-settings: 184px / --rail-exam: 232px 供设置页与模考 runner 使用。

06

断点

Breakpoints

由 21 个断点值收敛而来：原先 style.css 使用 769 / 768 / 1024 / 1280 / 640，Vue 侧又引入 900（×7）/ 1180 / 1100 / 960 / 880 / 760 / 600 / 480 / 420 / 400，共 21 处；v3 只保留四档设备断点加一个移动内部档，全部由同一套 DOM 的 CSS 负责，JS 不再判断宽度。

断点令牌布局行为比例
375 设备基准 手机基准宽度：单列布局，底部导航六项 + mobile-top 顶栏；所有表格转卡片，抽屉转底部展开
640 --bp-mobile 移动内部档：表格 ↔ 卡片（同一 DOM，列名移入 ::before）；底部抽屉改为底部展开
768 --bp-nav 底导 ↔ 侧栏：≤768 隐藏侧栏与顶栏、显示底部导航；>768 显示顶栏与侧栏
1024 --bp-rail 侧栏完整 ↔ 仅图标：≤1024 侧栏收成 64px 图标轨，文字与学习状态块隐藏
1440 --bp-max 内容最大宽度：统一纸面 1120 封顶，两侧留白，内容不再随窗口拉伸

比例条以 1440px 为满尺。三档布局互斥清晰：>1024 完整侧栏；769–1024 图标侧栏（无底栏）；≤768 底导——不存在某一档同时挂两套导航规则的情况。

07

动效

Motion

四档时长加两条曲线。小交互 150–300ms，大过渡不超过 400ms，退出取入场约 65%——离开永远比到达短。点击每张卡片可按该档时长播放一次填充。

--dur-fast150ms
微反馈：hover、聚焦、颜色过渡
--dur-base220ms
默认过渡：分段选中、进度填充、抽屉与对话框入场
--dur-slow320ms
大过渡：整块面板位移（规范档位）
--dur-exit145ms
退出：约 base 的 65%，离场快于入场
--ease-out cubic-bezier(.2, .6, .2, 1)

入场与状态过渡的默认曲线：起步快、收尾缓，界面有「落定」感。抽屉、对话框、分段选中、进度填充都用它。

--ease-in cubic-bezier(.4, 0, 1, 1)

退出加速曲线：元素离场时越来越快，配合 --dur-exit 让离开比到达更短。--ease 与 --ease-out 同值，保留为别名。

width 220ms cubic-bezier(.2,.6,.2,1)

演示用的是控件库里真实的 .progress / .progress-fill，其过渡即 width var(--dur-base) var(--ease-out)。prefers-reduced-motion: reduce 时，ee.css 全局把 animation 与 transition 降到 .001ms，本页演示一并降级，不做例外。
