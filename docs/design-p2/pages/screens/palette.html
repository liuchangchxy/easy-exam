快捷入口

规格段 · 对现状的修正

命令面板（Ctrl/⌘+K）覆盖在今天页之上
补齐入口

现状的命令面板只有「今天 / 题库 / 复习 / 模考 / 资料 / 设置 / 退出」，导入、新建题库、查看错题都要回到页面里找。修正后命令组包含：今天、题库、复习、模考、资料、设置、新建题库、导入、开始到期复习、查看错题、切换主题、切换语言、退出。

aria-expanded 不再恒真

现状里输入框的 aria-expanded 写死为 true。修正后它跟随列表实际状态：有结果时为 true，无结果（空查询之外的过滤无命中）时为 false，并显示「没有匹配的命令或题库」。

键盘

↑ ↓在题库与命令之间移动高亮（aria-activedescendant 同步） Enter执行当前高亮项；题库行内的「练习」按钮打开该题库的开始学习决策（与首页「开始」同一条链路，不跳过决策直接开会话） Esc关闭面板，焦点回到打开它的按钮 ⌘K打开 / 关闭命令面板
