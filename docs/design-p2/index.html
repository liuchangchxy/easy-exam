载体选择规则

同一件事该做成页面、对话框、抽屉还是菜单
场景载体理由
创建或编辑一个短实体（题库、资料、章节、标签、成员邀请）对话框有明确提交边界，不依赖主内容上下文
查看或编辑主内容某一侧的内容（题目编辑、版本历史、字段映射帮助）抽屉需要与主内容对照
对一行或多行的上下文操作（题目行「更多」、批量条操作）菜单操作集短，不打断浏览
同一实体下并列的子视图（工作区六页签、资料四分部）页签语义平级，URL 记录当前页签
改变集合定义或过滤条件（我的/共享给我、资料类型）分段 + URL是查询条件，不是视图
多步骤且每步需要专注的长任务（导入向导）页面 + 步骤条需要面包屑、可中断续做
沉浸式单任务（普通练习、考试会话）全屏 runner排除一切导航干扰
破坏性或不可逆确认（删除、转移所有权、交卷、退出放弃）危险对话框必须显式二次确认

04全产品统一规则

这五条是跨域裁决的直接落地，任何一个屏违反都算设计缺陷。完整八态与外壳规则见状态与外壳。

五条硬规则
规则依据设计落地
批量结果只有两项 CR-27 「成功 X · 无须变更 Y」，`X + Y = 已选 N`。整批拒绝则零写入 + 可读原因。不存在「跳过 Z」；「已经处于目标状态」是无须变更，不是校验失败。
考试会话三段式 CR-31 作答窗口 → 宽限 60 秒（仅同步）→ 服务端收卷。「作答窗口结束」不是会话终止；宽限期是 info 级正常状态，不得变红或报错。
复习只有四视图 CR-29 待复习 / 错题 / 薄弱 / 斩杀。「全部」与「到期」是同一集合，只有一个页签。学习档案是独立路由。
越权禁用不隐藏 FN-421 控件禁用 + 可读原因，入口保留。403 两变体：看不到（整页）/ 看得到不能操作（禁用）。
没有 AI 也要完整可用 P-8 / FN-518 每个 AI 入口都有非 AI 替代路径；未配置是 info 态不是错误态；配好之后能力增强，配不好功能不消失。

05跨端规则

三档共享同一套 DOM 与同一套语义，只改布局与交互方式。判断标准是「这只手现在能做什么」，不是「这块屏有多宽」。

四档断点
档位导航布局与交互
>1024 桌面完整侧栏 236px + 顶栏纸面居中 1120px（宽变体 1320px）；鼠标 + 快捷键；hover 有反馈
769–1024 平板侧栏收成 64px 图标轨纸面通栏；触屏；hover 失效的状态必须有 active/selected 兜底
641–768 小平板图标轨 + 底栏同时可用单列；表格转卡片；底部固定操作区
≤640 手机侧栏隐藏，底部导航 6 项单列；单手拇指可达；触摸目标 ≥44px；答题卡改底部抽屉；长文限宽 68ch；表单不被软键盘遮

移动端不是桌面的缩小版。答题卡从右侧常驻栏改为底部抽屉（常驻栏会把题干挤到一行三个字）；固定操作区只放当前步骤的主操作；软键盘弹出时页面滚到当前输入框，提交按钮随键盘上浮。

07交给 P3 的边界

P2 到此为止：产品 IA、完整页面布局与视觉表达、全局设计系统与共享组件、关键交互形式、全部状态的设计表达、跨端规则，都已定稿。P3 把这些实现成可操作可验证的交互原型。

P2 有意没做的事

没有实现完整业务交互（不模拟网络请求、不做真实数据流转）、没有写生产代码、没有为了凑数量添加页面。P2 的验证标准是「设计是否完整、统一、可实现」，不是「能不能跑通一个业务流程」。
